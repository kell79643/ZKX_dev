每批warmup 5。`firwin`以`scale`作为numtaps，固定`cutoff=2、fs=16、pass_zero=lowpass、
scale=true`，规模为33、257、513、768、1024、2048、4096，5种dtype用例，每点
5批×20=100个正式样本，每批warmup 5。dtype是TASK_F类型用例标签；`firwin`输出存储遵循

### 7.1 图13可直接绘制的数据与口径

`cpu_gpu_speedup = cpu_mean_ms / gpu_mean_ms`。数值大于1表示 GPU 更快，小于1表示
CPU 更快。图13应画成两个分面：`unit_impulse` 的 `scale` 表示输出元素数，`firwin`
的 `scale` 表示滤波器 taps；两者横轴含义不同，不应连接成同一条曲线。每个分面按
`input_dtype` 画5条折线，并增加 `y=1` 的水平基准线。建议 X 轴使用对数刻度，Y 轴
保持线性刻度；数据点使用 marker，避免把采样点之间的连线误读为额外实测结果。

`CPU mean/GPU mean`中心值，不是单次运行，也不是不同规模之间插值得到的数值。
