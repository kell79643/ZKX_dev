## 修改 1：step6.cu truth 公式

### 文件

[step6.cu](file:///c:\Users\Lenovo\Desktop\ZKX\Task2\task2_gpu_cpu\step6\step6.cu) `prepare_step6_host_inputs` 函数内 truth 计算块。

### 修改前

```cpp
const float filter_delay_samples =
    (static_cast<float>(config.filter_taps) - 1.0F) / 2.0F;
const float spline_delay_samples =
    (static_cast<float>(kSplineTapCount) - 1.0F) / 2.0F;

    static_cast<float>(state.feature_bundle.size() - 1);

    (0.5F * bundle_scale + static_cast<float>(config.target_delay_samples) +
     filter_delay_samples + spline_delay_samples) /

```

### 修改后

```cpp
const float filter_delay_samples =
    (static_cast<float>(config.filter_taps) - 1.0F) / 2.0F;
const float spline_delay_samples =
    (static_cast<float>(kSplineTapCount) - 1.0F) / 2.0F;
const float crop_shift_samples =
    static_cast<float>(config.step3_crop_each);
const float bundle_scale =
    static_cast<float>(state.feature_bundle.size() - 1);
// feature_bundle 坐标系 = echo 坐标系 - step3_crop_each + filter_delay + spline_delay
state.truth =
    (0.5F * bundle_scale + static_cast<float>(config.target_delay_samples) +
     filter_delay_samples + spline_delay_samples - crop_shift_samples) /
    bundle_scale;
```

## 公式对照

| 项 | 第一轮修正后 | 第二轮修正后 | 来源 |
|---|---|---|---|
| 中心位置 | `0.5·(N−1)` | `0.5·(N−1)` | 回波位于窗口中点 |
| 目标延迟 | `+ target_delay_samples` | `+ target_delay_samples` | config |
| FIR 群延迟 | `+ (taps−1)/2` | `+ (taps−1)/2` | `config.filter_taps` |
| B样条群延迟 | `+ (weights−1)/2` | `+ (weights−1)/2` | `kSplineTapCount = 9` |
| step3 裁剪补偿 | **缺失** | `- step3_crop_each` | `config.step3_crop_each` |
| 归一化 | `/ (N−1)` | `/ (N−1)` | 保留 [0,1] |
