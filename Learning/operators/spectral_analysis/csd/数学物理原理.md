# CSD (Cross Spectral Density) 算子数学物理原理

## 一、通用数学物理原理

### 原理 1:交叉谱密度的基本定义

交叉谱密度(Cross Spectral Density, CSD),又称互功率谱密度,是频域内描述两个平稳随机信号之间统计相关程度的方法。

#### 1.1 连续时间定义

对于两个平稳随机信号 $x(t)$ 和 $y(t)$,其交叉谱密度定义为:

$$S_{xy}(\omega) = \mathcal{F}\{R_{xy}(\tau)\} = \int_{-\infty}^{+\infty} R_{xy}(\tau) e^{-j\omega\tau} d\tau$$

其中 $R_{xy}(\tau)$ 是 $x(t)$ 和 $y(t)$ 的互相关函数:

$$R_{xy}(\tau) = E[x(t)y(t+\tau)]$$

#### 1.2 离散时间定义

对于离散时间信号 $x[n]$ 和 $y[n]$,交叉谱密度定义为:

$$S_{xy}(\omega) = \sum_{\tau=-\infty}^{+\infty} r_{xy}[\tau] e^{-j\omega\tau}$$

其中 $r_{xy}[\tau]$ 是离散互相关序列:

$$r_{xy}[\tau] = E[x[n]y[n+\tau]]$$

#### 1.3 基于傅里叶变换的定义

交叉谱密度也可以直接通过傅里叶变换定义:

$$S_{xy}(f) = \lim_{T \to \infty} \frac{1}{T} E[X_T^*(f) Y_T(f)]$$

其中 $X_T(f)$ 和 $Y_T(f)$ 是截断信号的傅里叶变换,$E[\cdot]$ 表示期望值(系综平均)。

**物理意义**:
- 交叉谱密度衡量两个信号在各个频率上的相关程度
- 保留相位信息,是复数谱
- 幅值表征相关强度,辐角(相位)表征两信号间的相位差

### 原理 2:交叉谱密度的性质

#### 2.1 复数性质

交叉谱密度是复数,可以分解为:

$$S_{xy}(f) = Co_{xy}(f) + j Qu_{xy}(f)$$

其中:
- $Co_{xy}(f)$:共谱(Co-spectrum),实部
- $Qu_{xy}(f)$:正交谱(Quadrature spectrum),虚部

#### 2.2 对称性

交叉谱密度满足以下对称性质:

$$S_{xy}(\omega) = S_{yx}^*(\omega)$$

即交换信号顺序后,新谱等于原谱的复共轭。

#### 2.3 与自功率谱密度的关系

当 $x(t) = y(t)$ 时,交叉谱密度退化为自功率谱密度(PSD):

$$S_{xx}(\omega) = \mathcal{F}\{R_{xx}(\tau)\}$$

#### 2.4 幅值与相位

交叉谱密度的幅值和相位分别为:

$$|S_{xy}(f)| = \sqrt{Co_{xy}^2(f) + Qu_{xy}^2(f)}$$

$$\angle S_{xy}(f) = \arctan\left(\frac{Qu_{xy}(f)}{Co_{xy}(f)}\right)$$

### 原理 3:Welch 方法估计 CSD

实际应用中,无法直接计算真实 CSD,需要从有限长度的采样数据估计。最常用的方法是 Welch 方法。

#### 3.1 Welch 方法基本步骤

Welch 方法通过以下步骤估计交叉谱密度:

1. **分段**:将长度为 $N$ 的信号分成 $K$ 个重叠的段,每段长度为 $L$

2. **加窗**:对每段数据应用窗函数 $w[n]$:

$$x_k[n] = x[n + kD] \cdot w[n], \quad n = 0, 1, ..., L-1$$

其中 $D$ 是段间步长,$D = L - N_{overlap}$

3. **FFT**:对每段加窗数据计算 FFT:

$$X_k(f) = \sum_{n=0}^{L-1} x_k[n] e^{-j2\pi fn/f_s}$$

$$Y_k(f) = \sum_{n=0}^{L-1} y_k[n] e^{-j2\pi fn/f_s}$$

4. **交叉周期图**:计算每段的交叉周期图:

$$P_{xy,k}(f) = \frac{X_k^*(f) Y_k(f)}{f_s \cdot U}$$

其中 $U$ 是窗函数的归一化因子:

$$U = \sum_{n=0}^{L-1} |w[n]|^2$$

5. **平均**:对所有段的交叉周期图求平均:

$$\hat{S}_{xy}(f) = \frac{1}{K} \sum_{k=0}^{K-1} P_{xy,k}(f)$$

#### 3.2 归一化与单位

根据 `scaling` 参数的不同,有两种归一化方式:

**密度模式(density)**:
$$P_{xy}(f) = \frac{X^*(f) Y(f)}{f_s \cdot U}$$
单位: $V^2/Hz$

**谱模式(spectrum)**:
$$P_{xy}(f) = \frac{X^*(f) Y(f)}{(\sum w[n])^2}$$
单位: $V^2$

### 原理 4:相干函数与频响函数

交叉谱密度是计算其他重要频域指标的基础。

#### 4.1 相干函数(Coherence)

相干函数衡量两个信号在各个频率上的线性相关程度:

$$\gamma_{xy}^2(f) = \frac{|S_{xy}(f)|^2}{S_{xx}(f) S_{yy}(f)}$$

取值范围: $0 \le \gamma_{xy}^2(f) \le 1$

- $\gamma_{xy}^2(f) = 1$:完全线性相关
- $\gamma_{xy}^2(f) = 0$:不相关

#### 4.2 频响函数(Frequency Response Function, FRF)

频响函数描述线性时不变系统的传递特性:

$$H(f) = \frac{S_{xy}(f)}{S_{xx}(f)}$$

其中 $x(t)$ 是输入,$y(t)$ 是输出。

#### 算法 1:基于 Welch 方法的 CSD 估计

**输入条件**:
- 两个时域信号 $x$ 和 $y$
- 采样频率 $f_s$
- 窗函数 $w[n]$

- FFT 长度 $N_{FFT}$ (`nfft`)
- 去趋势方式
- 缩放模式
- 平均方式

**执行步骤**:

1. **输入验证与预处理**:
   - 将输入转换为 CuPy 数组
   - 检查信号长度,必要时进行零填充
   - 设置默认参数

2. **分段与加窗**:
   - 计算段间步长: $D = L - N_{overlap}$
   - 使用 `_as_strided` 创建滑动窗口视图
   - 对每段应用窗函数 $w[n]$

3. **去趋势**:
   - 对每段数据去趋势('constant'去均值,'linear'去线性趋势)

4. **FFT 计算**:
   - 对每段加窗去趋势后的数据计算 FFT:
     - 实信号:使用 `rfft` 得到单边谱
     - 复信号:使用 `fft` 得到双边谱

5. **交叉谱计算**:
   - 计算互谱: $P_{xy}(f) = X_k^*(f) Y_k(f)$
   - 应用缩放因子:
     - 密度模式: `scale = 1.0 / (fs * (win * win).sum())`
     - 谱模式: `scale = 1.0 / win.sum() ** 2`
   - 单边谱修正:除直流和奈奎斯特频率外,其他频率乘以 2

6. **平均**:
   - 对所有段的互谱求平均:
     - 平均值: `Pxy = Pxy.mean(axis=-1)`
     - 中值: `Pxy = cp.median(Pxy, axis=-1) / _median_bias(Pxy.shape[-1])`

## 五、实例与验证

### 5.1 手算示例

假设两个简单的离散信号:

$$x[n] = [1, 2, 3, 4]$$

$$y[n] = [2, 3, 4, 5]$$

使用 Welch 方法估计交叉谱密度(假设 $f_s = 1$ Hz,段长度 $L = 4$,无重叠,矩形窗):

1. **加窗**:使用矩形窗 $w[n] = [1, 1, 1, 1]$

2. **FFT**:

$$X(f) = \sum_{n=0}^{3} x[n] e^{-j2\pi fn} = 1 + 2e^{-j2\pi f} + 3e^{-j4\pi f} + 4e^{-j6\pi f}$$

$$Y(f) = \sum_{n=0}^{3} y[n] e^{-j2\pi f} = 2 + 3e^{-j2\pi f} + 4e^{-j4\pi f} + 5e^{-j6\pi f}$$

3. **交叉谱**:

$$P_{xy}(f) = X^*(f)Y(f)$$

4. **归一化**(密度模式):

$$\hat{S}_{xy}(f) = \frac{P_{xy}(f)}{f_s \cdot \sum w^2[n]} = \frac{P_{xy}(f)}{1 \cdot 4}$$

### 5.2 常见误区

1. **混淆 PSD 与 CSD**:
   - PSD(Power Spectral Density): 单信号的自功率谱密度,$S_{xx}(f) = E[|X(f)|^2]$
   - CSD(Cross Spectral Density): 双信号的互功率谱密度,$S_{xy}(f) = E[X^*(f)Y(f)]$
   - 当 $x = y$ 时,CSD 退化为 PSD

2. **忽略相位信息**:
   - CSD 是复数,包含幅度和相位
   - 幅度表征相关强度,相位表征相位差
   - 在频响分析和相干分析中,相位信息至关重要

3. **平均方式选择不当**:
   - 均值平均(`average='mean'`): 常规情况,降低方差
   - 中值平均(`average='median'`): 存在脉冲干扰或离群值时更鲁棒
   - 选择不当可能影响估计质量

4. **窗函数与重叠率配合不当**:
   - Hann 窗默认 50% 重叠,满足 COLA 约束
   - 其他窗函数可能需要不同的重叠率
   - 重叠率过低会损失数据利用效率,过高会增加计算量
