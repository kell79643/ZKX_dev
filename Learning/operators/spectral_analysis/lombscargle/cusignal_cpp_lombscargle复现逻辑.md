## 阶段说明

根据 `Learning/AGENTS.md` 规范,阶段三必须在用户明确要求后才开始。本阶段将同时覆盖 CPU 和 GPU 版本,包括:

1. 当前学习版本的完整 Git SHA、提交时间、分支、相关文件 dirty 状态
2. 对外接口、声明文件、实现文件和该提交中的准确行号
3. CPU 调用链、主要数据结构和逐步算法
4. GPU 调用链、host wrapper、kernel 启动和 device 计算逻辑
5. template、类型分发、显式实例化、内存布局及数据搬运
6. grid、block、线程索引和每个线程负责的数据范围
7. 同步、临时缓冲区、FFT/平台库调用与错误处理
8. 数学/物理原理到 CPU 代码、GPU 代码的三方映射
9. 与 cuSignal Python 实现相同、等价替换和有意不同的部分
10. 精度、dtype、边界条件及 ZQ500 平台限制

**请用户明确指示是否进入阶段三学习。**
