# gausspulse 数学物理原理

## 独立原理资格核验

`gausspulse`（Gaussian modulated sinusoidal pulse，高斯包络调制正弦脉冲）在脱离 cuSignal 代码后，确实对应一个公认的信号处理与数学对象——**高斯包络调制正弦脉冲**（亦称高斯射频脉冲、Gaussian RF pulse）。它在雷达、声纳、超声、光学和通信等领域被广泛用作发射脉冲和窗函数，具有独立的数学定义和物理意义。因此，本算子具有独立的数学物理原理，不需要虚构。

---

## 原理 1：高斯函数及其时频性质

### 1.1 定义

高斯函数（Gaussian function）的连续形式为：

$$g(t) = A \exp\!\left(-\frac{(t - t_0)^2}{2\sigma^2}\right)$$

其中：

- $A$：峰值幅度；
- $t_0$：峰值时间位置（平移中心）；
- $\sigma$：标准差，控制波形宽度。

当 $A=1,\; t_0=0$ 时，简化为：

$$g(t) = \exp\!\left(-\frac{t^2}{2\sigma^2}\right)$$

也可以等价写成：

$$g(t) = \exp(-a\,t^2)$$

其中 $a = \dfrac{1}{2\sigma^2}$，这是 gausspulse 代码中使用的形式。

### 1.2 高斯函数的傅里叶变换

高斯函数的傅里叶变换仍为高斯函数：

$$\mathcal{F}\{e^{-a t^2}\} = \sqrt{\frac{\pi}{a}}\,\exp\!\left(-\frac{\pi^2 f^2}{a}\right)$$

其中 $f$ 为频率（Hz）。这一性质是高斯函数独有的——它是唯一在时域和频域同为高斯形状的函数。

### 1.3 时频不确定性原理

对于任何信号，时域标准差 $\sigma_t$ 和频域标准差 $\sigma_f$ 满足：

$$\sigma_t \cdot \sigma_f \geq \frac{1}{4\pi}$$

高斯函数是**唯一**使等号成立的函数，即在时频联合分辨意义上达到最优。这使得高斯包络在需要时频同时集中的场景中具有特殊地位。

### 1.4 FWHM 与标准差的关系

强度（功率）的半高全宽（FWHM）：

$$\tau_p = 2\sqrt{2\ln 2}\;\sigma = 2\sqrt{\frac{\ln 2}{a}}$$

这是光学和脉冲分析中常用的脉冲宽度度量。

## 原理 2：高斯包络调制正弦脉冲

### 2.1 定义

将高斯函数作为包络，对正弦载波进行幅度调制，得到高斯包络调制正弦脉冲：

$$s(t) = \exp(-a\,t^2)\,\cos(2\pi f_c\,t)$$

其复数表示为：

$$\tilde{s}(t) = \exp(-a\,t^2)\,\exp(j\,2\pi f_c\,t)$$

其中：

- $a$：高斯包络的时间衰减系数，$a > 0$；
- $f_c$：载波（中心）频率（Hz）；
- $\exp(-a\,t^2)$：高斯包络（实数幅度调制）；
- $\cos(2\pi f_c\,t)$ 或 $\exp(j\,2\pi f_c\,t)$：载波振荡。

实际信号取复数表示的实部：

$$s(t) = \operatorname{Re}\{\tilde{s}(t)\} = \exp(-a\,t^2)\,\cos(2\pi f_c\,t)$$

### 2.2 包络与调制的物理含义

在 $s(t) = \underbrace{\exp(-at^2)}_{\text{包络}} \cdot \underbrace{\cos(2\pi f_c t)}_{\text{载波}}$ 中，包络和调制各有明确的物理角色。

#### 包络的物理含义

1. **幅度轮廓**：$\pm\exp(-at^2)$ 是载波振荡的上、下包络线。信号在两条包络线之间来回振荡，包络描绘了振荡幅度的时变轮廓。

2. **能量聚集与脉冲成型**：纯粹载波 $\cos(2\pi f_c t)$ 是无限长等幅振荡，不携带时间定位信息。包络将无限长载波"裁剪"为有限持续时间的脉冲：$\exp(-at^2)$ 在 $t=0$ 处取峰值 1，向两侧对称衰减，使信号能量集中在 $t=0$ 附近。$a$ 越大，包络越窄，脉冲越短，能量越集中。

3. **频域带宽控制**：由原理 1，高斯函数的傅里叶变换仍为高斯函数，因此包络形状直接决定脉冲的频域带宽。$a$ 越大（时域越窄）→ 频域越宽；$a$ 越小（时域越宽）→ 频域越窄——时频不确定性原理在此直接体现。

#### 调制的物理含义

1. **频谱搬移**：包络与载波相乘，等价于将包络的基带频谱（中心在 0 Hz）搬移到 $\pm f_c$：

$$\mathcal{F}\{g(t) \cdot \cos(2\pi f_c t)\} = \frac{1}{2}[G(f - f_c) + G(f + f_c)]$$

对于高斯包络，$G(f)$ 仍为高斯形，调制后在 $\pm f_c$ 处各产生一个高斯形频谱峰。

2. **从基带到带通**：未经调制的 $\exp(-at^2)$ 是基带信号，频谱集中在直流附近，不适合通过天线或换能器发射。调制将信号搬移到 $f_c$，使其成为带通信号，便于在物理信道中传输。雷达发射脉冲、超声换能器激励信号和通信射频载波都是带通信号。

3. **载波频率的角色**：$f_c$ 决定频谱中心位置，但不影响包络形状和带宽绝对值。在雷达中 $f_c$ 对应发射频率，在超声中对应换能器谐振频率，在通信中对应信道频率。

4. **信息与载波的功能分离**：包络承载脉冲的时频定位信息（何时发射、持续多长、带宽多宽），载波仅提供传输频率选择。这种功能分离是所有调制信号的基本特征，也是 gausspulse 结构的物理本质。

### 2.3 同相分量、正交分量和包络

从复数表示 $\tilde{s}(t) = \exp(-a\,t^2)\,\exp(j\,2\pi f_c\,t)$ 展开：

- **同相分量（In-phase, I）**：$y_I(t) = \exp(-a\,t^2)\,\cos(2\pi f_c\,t)$
- **正交分量（Quadrature, Q）**：$y_Q(t) = \exp(-a\,t^2)\,\sin(2\pi f_c\,t)$
- **包络（Envelope）**：$y_{\text{env}}(t) = \exp(-a\,t^2)$

三者满足 $|y_I + j\,y_Q| = y_{\text{env}}$。

### 2.4 频域特性

利用傅里叶变换的调制性质（频移定理），$\tilde{s}(t)$ 的频谱为：

$$\tilde{S}(f) = \sqrt{\frac{\pi}{a}}\,\exp\!\left(-\frac{\pi^2(f - f_c)^2}{a}\right)$$

频谱以 $f_c$ 为中心呈高斯形状，频域标准差为 $\sigma_f = \dfrac{\sqrt{a}}{2\pi}$，与高斯包络一样达到时频不确定性下限。

## 原理 3：分数带宽与衰减系数的推导

### 3.1 分数带宽定义

分数带宽（fractional bandwidth）$b_w$ 定义为：在频域中，幅度下降到参考电平 $r$（通常为 $-6$ dB，即 $r = 10^{b_{wr}/20}$）时对应的频率范围，归一化到中心频率：

$$b_w = \frac{\Delta f}{f_c}$$

其中 $\Delta f$ 是幅度下降到参考电平时的双边带宽。

### 3.2 由 $b_w$ 和 $b_{wr}$ 推导 $a$

频谱幅度在 $f = f_c + f_c\,b_w/2$ 处下降到参考电平 $r$：

$$\sqrt{\frac{\pi}{a}}\,\exp\!\left(-\frac{\pi^2\,(f_c\,b_w/2)^2}{a}\right) = r \cdot \sqrt{\frac{\pi}{a}}$$

两边约去 $\sqrt{\pi/a}$，取对数：

$$-\frac{\pi^2 f_c^2 b_w^2}{4a} = \ln r$$

解出 $a$：

$$a = -\frac{(\pi f_c b_w)^2}{4\,\ln r}$$

其中 $r = 10^{b_{wr}/20}$，$b_{wr}$ 的单位为 dB（通常为负值，如 $-6$ dB）。

当 $b_{wr} = -6$ dB 时，$r = 10^{-6/20} = 10^{-0.3} \approx 0.5012$，即半功率点（-3 dB 功率 = -6 dB 幅度），此时分数带宽即为常用的 -6 dB 幅度带宽。

### 3.3 截止时间推导

时域包络下降到参考电平 $t_{\text{ref}}$（通常 $t_{\text{ref}} = 10^{t_{pr}/20}$，$t_{pr}$ 单位 dB）的时刻 $t_c$：

$$\exp(-a\,t_c^2) = t_{\text{ref}}$$

解出：

$$t_c = \sqrt{\frac{-\ln t_{\text{ref}}}{a}}$$

当 $t_{pr} = -60$ dB 时，$t_{\text{ref}} = 10^{-60/20} = 10^{-3} = 0.001$，即包络衰减到千分之一。

## 原理 4：Morlet 小波与高斯调制脉冲的关系

### 4.1 Morlet 小波定义

Morlet 小波（Gabor 小波）定义为：

$$\psi(t) = \pi^{-1/4}\,e^{-t^2/2}\,e^{j\omega_0 t}$$

其中 $\omega_0$ 是无量纲频率参数，通常取 $\omega_0 \geq 5$ 以满足小波容许条件。

### 4.2 与 gausspulse 的异同

| 方面 | gausspulse | Morlet 小波 |
|------|-----------|-------------|
| 包络 | $\exp(-a\,t^2)$，$a$ 由 $f_c, b_w, b_{wr}$ 决定 | $\pi^{-1/4}\exp(-t^2/2)$，固定宽度 |
| 载波 | $\exp(j2\pi f_c t)$，$f_c$ 为实际频率 | $\exp(j\omega_0 t)$，$\omega_0$ 为无量纲参数 |
| 归一化 | 无能量归一化因子 | $\pi^{-1/4}$ 保证单位能量 |
| 容许条件 | 不要求满足小波容许条件 | 要求 $\omega_0$ 足够大使均值为零 |
| 用途 | 生成指定带宽的脉冲信号 | 时频分析中的基函数 |

两者本质都是"高斯包络 × 复正弦"的数学形式，但 gausspulse 以工程参数（中心频率、分数带宽）为导向，Morlet 小波以满足小波数学条件为导向。

## 原理 5：参数变化对波形、频谱和精度的影响

### 5.1 $f_c$（中心频率）

- $f_c$ 增大 → 载波振荡加快，单位时间内周期数增多；
- $f_c$ 不影响包络形状和脉冲宽度；
- 频谱中心右移，但带宽绝对值不变。

### 5.2 $b_w$（分数带宽）

- $b_w$ 增大 → $a$ 增大 → 包络更窄 → 时域脉冲更短；
- 同时频域带宽 $\Delta f = f_c \cdot b_w$ 增大；
- $b_w$ 很小时，脉冲持续多个载波周期，频谱非常集中；
- $b_w$ 接近 1 或更大时，脉冲仅持续少数载波周期，频谱展宽。

### 5.3 $b_{wr}$（带宽参考电平）

- $b_{wr}$ 变得更负（如从 -6 dB 变为 -10 dB）→ 同一 $b_w$ 下 $a$ 减小 → 包络更宽；
- 这是因为更低的参考电平意味着在更远的频率处达到指定带宽比，需要更宽的包络。

### 5.4 数值精度注意事项

- 当 $a\,t^2$ 很大时（远离中心的尾部），$\exp(-a\,t^2)$ 下溢到零，这是正确行为；
- 当 $a$ 非常大时（极窄脉冲），离散采样可能无法充分表示包络形状，需要足够高的采样率；
- `cutoff` 模式下计算 $t_c$ 时，如果 $t_{pr}$ 非常负（如 -100 dB），$-\ln(t_{\text{ref}})$ 变大，截止时间增大。

## 手算示例

设 $f_c = 1000$ Hz，$b_w = 0.5$，$b_{wr} = -6$ dB。

1. 参考电平：$r = 10^{-6/20} = 10^{-0.3} \approx 0.5012$

2. 衰减系数：

$$a = -\frac{(\pi \times 1000 \times 0.5)^2}{4 \times \ln(0.5012)} = -\frac{(\pi \times 500)^2}{4 \times (-0.6931)} = \frac{(500\pi)^2}{2.7726}$$

$$a = \frac{2{,}467{,}401.1}{2.7726} \approx 889{,}965$$

3. 包络：$y_{\text{env}}(t) = \exp(-889965\,t^2)$

4. 在 $t = 0$ 处包络为 1（峰值），在 $t = 0.001$ s 处：

$$y_{\text{env}}(0.001) = \exp(-889965 \times 10^{-6}) = \exp(-0.890) \approx 0.411$$

5. 截止时间（$t_{pr} = -60$ dB，$t_{\text{ref}} = 0.001$）：

$$t_c = \sqrt{\frac{-\ln(0.001)}{889965}} = \sqrt{\frac{6.908}{889965}} \approx \sqrt{7.76 \times 10^{-6}} \approx 0.00278\;\text{s}$$

验证：$y_{\text{env}}(0.00278) = \exp(-889965 \times 0.00278^2) = \exp(-6.88) \approx 0.00103 \approx 0.001$ ✓

## 常见混淆与误区

1. **$b_w$ 不是绝对带宽**：$b_w = 0.5$ 不表示带宽是 0.5 Hz，而是绝对带宽 $\Delta f = f_c \times b_w = 500$ Hz。
2. **$b_{wr}$ 是幅度参考，不是功率参考**：$b_{wr} = -6$ dB 对应幅度降到一半（即功率降到 1/4，亦即 -3 dB 功率点），不是 -6 dB 功率点。
3. **gausspulse 不是 Morlet 小波**：虽然数学形式类似，但 gausspulse 无能量归一化，不要求满足容许条件，参数化方式也不同。
4. **复数表示的实部才是物理信号**：$\exp(-at^2)\exp(j2\pi f_c t)$ 的实部是 $\exp(-at^2)\cos(2\pi f_c t)$，虚部 $\exp(-at^2)\sin(2\pi f_c t)$ 是正交分量。
5. **$a$ 不是标准差的倒数**：$a = 1/(2\sigma^2)$，标准差 $\sigma = 1/\sqrt{2a}$。

## cuSignal 23.08.00 实际采用的算法

### cuSignal 算法 1：高斯包络调制余弦脉冲（默认模式）

**输入条件**：$t$ 为数组，$f_c \geq 0$，$b_w > 0$，$b_{wr} < 0$，`retquad=False`，`retenv=False`

**执行步骤**：

1. 由 $b_{wr}$ 计算参考电平：$r = 10^{b_{wr}/20}$
2. 计算衰减系数：$a = -\dfrac{(\pi f_c b_w)^2}{4\,\ln r}$
3. 计算同相分量：$y_I = \exp(-a\,t^2)\,\cos(2\pi f_c\,t)$
4. 返回 $y_I$

**源码位置**：
- 函数定义：`Learning/cusignal-23.08.00/python/cusignal/waveforms/waveforms.py:221`
- kernel `_gausspulse_kernel_F_F`：同文件第166-175行
- 参数 $a$ 的计算：同文件第292-296行

### cuSignal 算法 2：高斯包络调制余弦脉冲 + 包络（retenv=True）

**输入条件**：同算法 1，但 `retenv=True`

**执行步骤**：同算法 1 步骤 1-3，额外计算并返回 $y_{\text{env}} = \exp(-a\,t^2)$

**源码位置**：kernel `_gausspulse_kernel_F_T`，同文件第177-186行

### cuSignal 算法 3：高斯包络调制复正弦脉冲（retquad=True）

**输入条件**：`retquad=True`，`retenv=False`

**执行步骤**：同算法 1 步骤 1-2，然后使用 `sincos` 同时计算正弦和余弦：
- $y_I = \exp(-a\,t^2)\,\cos(2\pi f_c\,t)$
- $y_Q = \exp(-a\,t^2)\,\sin(2\pi f_c\,t)$

**源码位置**：kernel `_gausspulse_kernel_T_F`，同文件第188-202行

### cuSignal 算法 4：高斯包络调制复正弦脉冲 + 包络（retquad=True, retenv=True）

**输入条件**：`retquad=True`，`retenv=True`

**执行步骤**：同算法 3，额外计算并返回 $y_{\text{env}} = \exp(-a\,t^2)$

**源码位置**：kernel `_gausspulse_kernel_T_T`，同文件第204-218行

### cuSignal 算法 5：截止时间计算（t='cutoff'）

**输入条件**：$t$ 为字符串 `'cutoff'`，$t_{pr} < 0$

**执行步骤**：
1. 同算法 1 步骤 1-2 计算 $a$
2. 计算时间参考电平：$t_{\text{ref}} = 10^{t_{pr}/20}$
3. 返回截止时间：$t_c = \sqrt{-\ln(t_{\text{ref}})\,/\,a}$

**源码位置**：同文件第298-305行

### 算法说明

- 步骤 1-2（参数 $a$ 的计算）是数学算法本身；
- 四个 CuPy ElementwiseKernel 是 GPU 并行计算的工程实现，将相同数学公式逐元素应用到数组上；
- `retquad` 和 `retenv` 的组合导致四种不同的输出签名，因此分别定义四个 kernel；
- 参数校验（$f_c \geq 0$、$b_w > 0$、$b_{wr} < 0$、$t_{pr} < 0$）是工程边界检查，不属于数学算法。
