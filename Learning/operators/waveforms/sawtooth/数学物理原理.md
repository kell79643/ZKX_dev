# sawtooth 算子 — 数学物理原理

## 独立原理资格核验

`sawtooth`（锯齿波）在脱离任何具体代码后，对应一个公认的数学对象——**锯齿波形（sawtooth wave）**，它是信号处理中四种基本周期波形（正弦波、方波、三角波、锯齿波）之一。它具有独立的数学定义、傅里叶级数展开、频谱特性和物理应用场景，绝非 dispatcher、helper 或便捷别名。因此，`sawtooth` 拥有独立的数学物理原理，下文按编号逐一展开。

---

## 一、通用定义、用途和典型输入输出

### 1.1 通用定义

锯齿波是一种**分段线性、周期性、非正弦**波形。在一个完整周期内，信号先沿直线匀速上升（或下降），然后在周期边界处瞬即回落（或跃升），形成形如锯齿的波形。

数学上，锯齿波最原始的定义基于**取整函数（floor function）** $\lfloor \cdot \rfloor$ 或**取模运算（mod）**，本质是提取变量的**小数部分（fractional part）**：

$$\{t\} = t - \lfloor t \rfloor = t \bmod 1, \quad 0 \le \{t\} < 1$$

此形式产生范围 $[0, 1)$、周期为 1 的锯齿波。为使其关于零点对称并取范围 $[-1, 1]$、与正弦波同相位，常用如下中心化定义：

$$x(t) = 2\left(\frac{t}{p} - \left\lfloor \frac{1}{2} + \frac{t}{p} \right\rfloor\right)$$

其中 $p$ 为周期。

### 1.2 用途

| 应用领域 | 具体用途 |
| --- | --- |
| 音频合成 | 减法合成的基本音色源，含全部整数次谐波，音色明亮刺耳；弓弦乐器（小提琴等）的弓-弦 slip-stick 机制近似锯齿驱动 |
| CRT 显示 | 水平/垂直偏转的扫描信号，控制电子束匀速扫过屏幕后快速回扫 |
| 开关电源 | PWM 控制中的比较基准信号，反馈电压与锯齿波比较产生占空比 |
| 信号测试 | 激励非线性系统，揭示频率相关行为 |
| 角度计算 | 自动化和机器人中，$\text{sawtooth}(\theta) = 2\arctan(\tan(\theta/2))$ 可避免 0°/360° 不连续 |

### 1.3 典型输入输出

- **输入**：时间数组 $t$（实数，单位为弧度或秒）；宽度参数 $w \in [0, 1]$（上升斜坡占整个周期的比例）
- **输出**：波形数组 $y \in [-1, 1]$（或 $w$ 越界时为 NaN）
- **周期**：$2\pi$（以弧度为单位的输入）；或 $p$（以秒为单位的输入，需配合频率 $f$，输入为 $2\pi f t$）

## 二、原理 1：分段线性定义与取模实现

### 2.1 原理内容

锯齿波的核心是在一个周期内用两条直线段拼接：一条**上升斜坡**（rising ramp）和一条**下降斜坡**（falling ramp）。`width` 参数 $w$ 控制上升斜坡在周期中所占的比例。

设周期 $T = 2\pi$，输入 $t$ 经取模后归约到 $[0, 2\pi)$：

$$t_{\text{mod}} = t \bmod 2\pi$$

则分段定义如下：

$$
y(t) = \begin{cases}
\dfrac{t_{\text{mod}}}{\pi w} - 1, & 0 \le t_{\text{mod}} < w \cdot 2\pi \quad \text{（上升段）} \\[8pt]
\dfrac{\pi(w + 1) - t_{\text{mod}}}{\pi(1 - w)}, & w \cdot 2\pi \le t_{\text{mod}} < 2\pi \quad \text{（下降段）}
\end{cases}
$$

### 2.2 各符号说明

| 符号 | 含义 | 取值范围 | 单位 |
| --- | --- | --- | --- |
| $t$ | 输入时间 | $\mathbb{R}$ | 弧度 |
| $w$ | 上升斜坡占比（width） | $[0, 1]$ | 无量纲 |
| $T = 2\pi$ | 波形周期 | 常数 | 弧度 |
| $t_{\text{mod}}$ | $t$ 取模 $2\pi$ 后的余数 | $[0, 2\pi)$ | 弧度 |
| $y$ | 输出波形值 | $[-1, 1]$ | 无量纲 |

### 2.3 推导

**上升段**：在 $t_{\text{mod}} = 0$ 处 $y = -1$，在 $t_{\text{mod}} = w \cdot 2\pi$ 处 $y = +1$，经过两点 $(0, -1)$ 和 $(2\pi w, 1)$ 的直线：

$$y = \frac{1 - (-1)}{2\pi w - 0} \cdot t_{\text{mod}} + (-1) = \frac{2}{2\pi w} t_{\text{mod}} - 1 = \frac{t_{\text{mod}}}{\pi w} - 1$$

**下降段**：在 $t_{\text{mod}} = 2\pi w$ 处 $y = +1$，在 $t_{\text{mod}} = 2\pi$ 处 $y = -1$，经过两点 $(2\pi w, 1)$ 和 $(2\pi, -1)$ 的直线：

$$y = \frac{-1 - 1}{2\pi - 2\pi w} (t_{\text{mod}} - 2\pi w) + 1 = \frac{-2}{2\pi(1 - w)} (t_{\text{mod}} - 2\pi w) + 1$$

化简：

$$y = \frac{-t_{\text{mod}} + 2\pi w}{\pi(1 - w)} + 1 = \frac{-t_{\text{mod}} + 2\pi w + \pi(1 - w)}{\pi(1 - w)} = \frac{\pi(w + 1) - t_{\text{mod}}}{\pi(1 - w)}$$

### 2.4 width 参数的极端情况

| $w$ 值 | 波形 | 说明 |
| --- | --- | --- |
| $w = 1$ | 纯上升锯齿波 | 无下降段，$t_{\text{mod}} = 2\pi$ 处从 $+1$ 跳至 $-1$ |
| $w = 0$ | 纯下降锯齿波（反向锯齿） | 无上升段，$t_{\text{mod}} = 0$ 处从 $-1$ 跳至 $+1$ |
| $w = 0.5$ | 对称三角波 | 上升段与下降段等长 |

**注意**：$w = 0$ 和 $w = 1$ 时，分母中分别出现 $\pi w = 0$ 和 $\pi(1 - w) = 0$，公式在数学上奇异。实际实现中需要特殊处理或依靠浮点极限行为。

### 2.5 离散形式与连续形式的关系

连续锯齿波 $x(t) = t - \lfloor t \rfloor$ 在每个整数点存在跳跃不连续。离散采样 $x[n] = x(n \cdot \Delta t)$ 后：

- 若采样间隔 $\Delta t$ 不是周期的整数约数，离散点不会恰好落在不连续处，波形看起来"连续"。
- 不连续点附近的离散值取决于浮点取模的精度，可能引入微小误差。
- 锯齿波**不是带限信号**（含无限谐波），采样后必然发生**混叠（aliasing）**，高频谐波折叠回低频。这是所有非带限波形采样的固有问题。

## 三、原理 2：傅里叶级数展开与频谱特性

### 3.1 傅里叶级数推导

考虑标准上升锯齿波（$w = 1$），在 $[-\pi, \pi)$ 上定义为 $f(t) = \frac{t}{\pi}$（范围 $[-1, 1]$），周期 $2\pi$。

由于 $f(t)$ 是**奇函数**，所有余弦系数 $a_n = 0$，只需求正弦系数 $b_n$：

$$b_n = \frac{1}{\pi} \int_{-\pi}^{\pi} \frac{t}{\pi} \sin(nt) \, dt$$

利用分部积分：

$$b_n = \frac{1}{\pi^2} \left[ -\frac{t \cos(nt)}{n} \bigg|_{-\pi}^{\pi} + \frac{1}{n} \int_{-\pi}^{\pi} \cos(nt) \, dt \right]$$

第二项积分为零，第一项：

$$b_n = \frac{1}{\pi^2} \left( -\frac{\pi \cos(n\pi)}{n} + \frac{-\pi \cos(-n\pi)}{n} \right) = \frac{-2\cos(n\pi)}{n\pi} = \frac{2(-1)^{n+1}}{n\pi}$$

因此标准锯齿波的傅里叶级数为：

$$\boxed{f(t) = \frac{2}{\pi} \sum_{n=1}^{\infty} \frac{(-1)^{n+1}}{n} \sin(nt) = \frac{2}{\pi} \left( \sin t - \frac{\sin 2t}{2} + \frac{\sin 3t}{3} - \cdots \right)}$$

### 3.2 频谱特性

| 特性 | 说明 |
| --- | --- |
| 谐波成分 | 包含**全部整数次谐波**（1 次、2 次、3 次、……），与方波（仅奇次谐波）不同 |
| 幅度衰减 | 第 $n$ 次谐波幅值为 $\frac{2}{n\pi}$，按 $1/n$ 衰减 |
| 收敛速度 | 比 $1/n$ 衰减的级数条件收敛，比三角波（$1/n^2$ 衰减）慢 |
| 直流分量 | $a_0 = 0$，无直流偏移 |
| 吉布斯现象 | 在不连续点 $t = \pm\pi$ 附近，部分和出现约 9% 的超调，不随项数增加而消失 |

### 3.3 反向锯齿波

反向（下降）锯齿波的傅里叶级数：

$$f_{\text{reverse}}(t) = -\frac{2}{\pi} \sum_{n=1}^{\infty} \frac{(-1)^{n+1}}{n} \sin(nt) = \frac{2}{\pi} \sum_{n=1}^{\infty} \frac{(-1)^{n}}{n} \sin(nt)$$

### 3.4 三角波（width = 0.5）的傅里叶级数

当 $w = 0.5$ 时退化为三角波，仅含奇次谐波，幅值按 $1/n^2$ 衰减：

$$f_{\text{tri}}(t) = \frac{8}{\pi^2} \sum_{k=0}^{\infty} \frac{(-1)^k}{(2k+1)^2} \sin((2k+1)t)$$

### 3.5 一般 width 的傅里叶级数

对任意 $w \in (0, 1)$，锯齿-三角波不再是纯奇或纯偶函数，傅里叶级数同时包含正弦和余弦项，且系数需对上升段和下降段分别积分。公式较为复杂，实践中**不通过傅里叶级数生成波形**，而是直接用分段线性公式逐点计算。

## 四、原理 3：width 参数对波形的连续变形

### 4.1 原理内容

`width` 参数 $w$ 是锯齿波族的**连续变形参数**，使波形从纯上升锯齿（$w=1$）经三角波（$w=0.5$）到纯下降锯齿（$w=0$）之间平滑过渡。

### 4.2 变形分析

| $w$ 变化方向 | 上升段 | 下降段 | 频谱变化 |
| --- | --- | --- | --- |
| $w$ 从 1 减小 | 上升段变短、斜率变陡 | 下降段出现并变长 | 偶次谐波从零开始增大 |
| $w = 0.5$ | 等长 | 等长 | 偶次谐波消失，仅奇次 |
| $w$ 从 0.5 减小到 0 | 上升段继续缩短 | 下降段变短、斜率变陡 | 偶次谐波再次出现 |

### 4.3 斜率表达式

- 上升段斜率：$k_{\text{rise}} = \frac{2}{2\pi w} = \frac{1}{\pi w}$
- 下降段斜率：$k_{\text{fall}} = \frac{-2}{2\pi(1-w)} = \frac{-1}{\pi(1-w)}$

当 $w \to 0$ 时，$k_{\text{rise}} \to \infty$（上升段趋于垂直跳变）；当 $w \to 1$ 时，$k_{\text{fall}} \to -\infty$（下降段趋于垂直跳变）。

### 4.4 width 为数组时的时变波形

`width` 也可以是与 $t$ 等长的数组，此时每个采样点使用不同的 $w$ 值，产生**波形随时间渐变**的效果，常用于音频合成中的包络调制。

## 五、算法成立的前提、边界条件和特殊情况

### 5.1 前提条件

1. 输入 $t$ 为实数或实数数组
2. $w \in [0, 1]$，超出此范围输出为 NaN
3. 周期 $T = 2\pi$ 由输入弧度约定隐含

### 5.2 边界条件

| 边界 | 行为 |
| --- | --- |
| $t_{\text{mod}} = 0$ | $y = -1$（上升段起点） |
| $t_{\text{mod}} = w \cdot 2\pi$ | $y = +1$（上升段终点 / 下降段起点） |
| $t_{\text{mod}} \to 2\pi^-$ | $y \to -1$（下降段终点） |
| $w = 0$ | 公式奇异；实现中 $t_{\text{mod}} < 0$ 恒假，全部走下降支；下降段公式 $\frac{\pi \cdot 1 - t_{\text{mod}}}{\pi \cdot 1} = 1 - \frac{t_{\text{mod}}}{\pi}$，产生从 $+1$ 到 $-1$ 的下降斜坡 |
| $w = 1$ | 公式奇异；$t_{\text{mod}} < 2\pi$ 恒真，全部走上升支；上升段公式 $\frac{t_{\text{mod}}}{\pi} - 1$，产生从 $-1$ 到 $+1$ 的上升斜坡 |

### 5.3 特殊情况

- **$w$ 为 NaN 或 Inf**：判断 $w > 1$ 或 $w < 0$ 为真，输出 NaN
- **$t$ 为 NaN**：`fmod(NaN, ...)` 返回 NaN，后续比较结果不确定，输出可能为 NaN
- **极小 $w$（接近 0）**：上升段斜率极大，浮点精度可能导致上升段内采样点不足
- **极大 $t$（接近浮点上限）**：`fmod` 精度下降，周期定位可能偏移

## 六、参数变化对波形、频谱、精度和稳定性的影响

| 参数变化 | 对波形的影响 | 对频谱的影响 | 精度/稳定性风险 |
| --- | --- | --- | --- |
| $w$ 增大 | 上升段占比增加 | 偶次谐波减小，趋向纯锯齿 | $w$ 接近 0 或 1 时斜率极大，采样点稀疏 |
| 采样率降低 | 不连续点附近细节丢失 | 高次谐波折叠（混叠加剧） | 无 |
| $t$ 值极大 | 波形周期不变 | 不变 | `fmod` 精度损失，周期边界漂移 |
| $w$ 为数组 | 波形形状随时间变化 | 瞬时频谱随时间变化 | 相邻 $w$ 差异大时波形不连续 |

## 七、手算验证小例子

### 例：$w = 0.5$（三角波），计算 $t = \frac{\pi}{2}$ 处的值

1. $t_{\text{mod}} = \frac{\pi}{2} \bmod 2\pi = \frac{\pi}{2}$
2. $w \cdot 2\pi = 0.5 \times 2\pi = \pi$
3. $t_{\text{mod}} = \frac{\pi}{2} < \pi$，走上升段
4. $y = \frac{\pi/2}{\pi \times 0.5} - 1 = \frac{\pi/2}{\pi/2} - 1 = 1 - 1 = 0$

验证：三角波在 $t = \frac{\pi}{2}$（即 $1/4$ 周期处）恰过零点，正确。

### 例：$w = 1$（纯上升锯齿），计算 $t = \pi$ 处的值

1. $t_{\text{mod}} = \pi \bmod 2\pi = \pi$
2. $w \cdot 2\pi = 2\pi$
3. $t_{\text{mod}} = \pi < 2\pi$，走上升段
4. $y = \frac{\pi}{\pi \times 1} - 1 = 1 - 1 = 0$

验证：纯上升锯齿在半周期处过零点，正确。

### 例：$w = 0.25$，计算 $t = \frac{\pi}{2}$ 处的值

1. $t_{\text{mod}} = \frac{\pi}{2}$
2. $w \cdot 2\pi = 0.25 \times 2\pi = \frac{\pi}{2}$
3. $t_{\text{mod}} = \frac{\pi}{2}$，**不满足** $t_{\text{mod}} < w \cdot 2\pi$（等号情况），走下降段
4. $y = \frac{\pi(0.25 + 1) - \pi/2}{\pi(1 - 0.25)} = \frac{1.25\pi - 0.5\pi}{0.75\pi} = \frac{0.75\pi}{0.75\pi} = 1$

验证：$t_{\text{mod}}$ 恰好等于上升段终点 $w \cdot 2\pi$，此时 $y = +1$（峰值），正确。

## 八、容易混淆的概念和常见误区

1. **锯齿波 vs 三角波**：锯齿波含全部整数次谐波（$1/n$ 衰减），三角波仅含奇次谐波（$1/n^2$ 衰减）。三角波是锯齿波在 $w = 0.5$ 时的特例，但两者频谱结构根本不同。

2. **上升锯齿 vs 反向锯齿**：$w = 1$ 是上升锯齿（从 $-1$ 线性升至 $+1$ 后跳回），$w = 0$ 是反向锯齿（从 $+1$ 线性降至 $-1$ 后跳回）。两者不是同一波形，互为负数关系。

3. **带限性**：锯齿波**不是带限信号**，包含无限谐波。数字采样必然产生混叠，这是数学事实而非实现缺陷。需要抗混叠滤波器或带限合成方法（如加法合成叠加有限项傅里叶级数）才能避免。

4. **吉布斯现象**：用有限项傅里叶级数逼近锯齿波时，在不连续点附近始终存在约 9% 的超调振荡，这不会因增加项数而消失，仅振荡区域变窄。

5. **周期约定**：SciPy/cuSignal 的 `sawtooth` 函数默认周期为 $2\pi$（弧度制输入）。若要产生物理频率 $f$ Hz 的波形，需传入 $t' = 2\pi f t$。

6. **$w = 0$ 和 $w = 1$ 的公式奇异**：分段公式中分母含 $w$ 和 $1-w$，但实现中这两个极端值恰好使其中一支的条件永远为真或永远为假，从而只走一支，不会真正除以零。

## 九、cuSignal 23.08.00 实际采用的算法

### 9.1 cuSignal 算法：GPU ElementwiseKernel 分段线性计算

cuSignal 的 `sawtooth` 使用 CuPy 的 `ElementwiseKernel` 将分段线性计算直接编译为 GPU CUDA kernel，逐元素并行执行。算法步骤如下：

1. **输入转换**：`t, w = cp.asarray(t), cp.asarray(width)`，将输入转为 CuPy 数组
2. **合法性检查**：若 $w > 1$ 或 $w < 0$，输出 NaN
3. **取模**：$t_{\text{mod}} = \text{fmod}(t, 2\pi)$
4. **分支判断**：
   - 若 $t_{\text{mod}} < w \cdot 2\pi$（上升段）：$y = t_{\text{mod}} / (\pi \cdot w) - 1$
   - 否则（下降段）：$y = (\pi(w + 1) - t_{\text{mod}}) / (\pi(1 - w))$
5. **返回**：输出数组 $y$

### 9.2 源码定位

| 内容 | 相对路径 | 行号 |
| --- | --- | --- |
| `_sawtooth_kernel`（CUDA ElementwiseKernel 定义） | `python/cusignal/waveforms/waveforms.py` | 第 17–42 行 |
| `sawtooth()` 函数定义 | `python/cusignal/waveforms/waveforms.py` | 第 45–80 行 |
| 模块导出 | `python/cusignal/waveforms/__init__.py` | 第 17 行 |

### 9.3 数学算法与工程实现的区分

- **数学算法本身**：分段线性公式（原理 1 的两个分支）
- **工程实现部分**：
  - CuPy `ElementwiseKernel` 编译与 GPU 并行调度
  - `cp.asarray` 的输入转换和类型广播
  - NaN 的 IEEE 754 位模式 `"0xfff8000000000000ULL"`
  - C++11 编译选项 `-std=c++11`

### 9.4 未采用的常见原理或算法

- **傅里叶加法合成**：未使用。加法合成需要叠加大量正弦项，计算量远大于分段线性直接计算，且仍受吉布斯现象困扰。对于波形生成任务，分段线性是最高效且精确的方法。
- **带限合成（BLIT / PolyBLEP）**：未使用。这些方法可消除混叠，但复杂度显著增加，cuSignal/SciPy 的 `sawtooth` 明确声明"not band-limited"。

| width 参数控制波形变形 | 原理 3 | 属于 | `w` 参数直接对应原理 3 的 $w$，$w=1$ 纯上升、$w=0$ 纯下降、$w=0.5$ 三角波 | `waveforms.py:28` 的 `w * 2.0 * M_PI` 分界判断 | width 参数的变形作用与原理 3 完全一致 |
| 未使用傅里叶级数 | 原理 2 | 未对应 | cuSignal 不通过傅里叶级数生成波形，原理 2 仅作为频谱分析的理论工具 | 源码中无任何 `sin`/`cos` 叠加逻辑 | 原理 2 是锯齿波的频域等价描述，但不是 cuSignal 的实现方法 |

## 十二、自检问题

1. **通用原理辨析**：锯齿波的分段线性定义（原理 1）和傅里叶级数（原理 2）是同一数学对象的两种等价表达吗？在什么意义上等价？在什么意义上不等价（如数值计算中）？

2. **cuSignal 算法选择**：cuSignal 为什么选择分段线性直接计算而不是傅里叶加法合成？两种方法在计算复杂度、精度和混叠行为上有什么差异？

3. **包含关系**：cuSignal 的 ElementwiseKernel 实现是否完全属于原理 1？有没有任何步骤超出了原理 1 的范围（如 NaN 处理、类型广播）？

4. **源码证据**：在 `waveforms.py` 的 kernel 代码中，`mask2` 和 `mask3` 的条件如何对应原理 1 中 $t_{\text{mod}} < w \cdot 2\pi$ 和 $t_{\text{mod}} \ge w \cdot 2\pi$ 的分段？等号情况（$t_{\text{mod}} = w \cdot 2\pi$）走哪一支？

5. **width 极端值**：$w = 0$ 和 $w = 1$ 时，分段公式的分母分别为 $\pi w$ 和 $\pi(1-w)$，理论上除零。cuSignal 的实现中为什么不会触发除零错误？请结合 `mask2` 的条件判断说明。

6. **混叠问题**：锯齿波不是带限信号，采样后必然混叠。cuSignal 的 docstring 明确声明了 "not band-limited"。在实际使用中，应如何评估和缓解混叠影响？

7. **傅里叶级数的作用**：原理 2（傅里叶级数）在 cuSignal 的实现中未使用，但它对理解锯齿波的频谱特性、谐波结构和吉布斯现象有什么不可替代的作用？
