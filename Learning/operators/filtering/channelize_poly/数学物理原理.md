## 〇、独立原理资格核验

在进入通用原理检索前，先确认 `channelize_poly` 在脱离 cuSignal 代码后是否对应一个公认的数学对象或信号处理算法。

`channelize_poly`（polyphase channelizer / 多相信道化器）对应数字信号处理中被普遍认可的 **多相 DFT 滤波器组信道化器（Polyphase DFT Filter Bank Channelizer）**，又称均匀 DFT 分析滤波器组的高效实现。该结构由 Bellanger 与 Daguet 在 1974 年首次提出（见参考资料 [1]），是软件无线电、频谱监测、射电天文、5G/6G 波形分析中宽带信号信道分解的标准技术，被 Vaidyanathan 在 IEEE 教程（参考资料 [2]）中作为多速率滤波器组的典范结构论述，Oppenheim 在 MIT 6.341 课程（参考资料 [3]）中以"调制滤波器组的 polyphase 实现 + DFT/FFT"为题专门推导。

因此 `channelize_poly` 拥有独立的数学物理原理，可以独立检索，**不是** dispatcher、helper、索引生成器或便捷别名。其核心由三个公认原理支撑：多相分解、均匀 DFT 调制滤波器组、多速率抽取信道化，下文分别编号阐述。

需要注意：cuSignal `channelize_poly` 的 docstring 明确写"channel spacing is equivalent to the number of channels used (zero overlap)"，即采用 **临界抽取（critically sampled，抽取因子 $D=M$）** 的简化版本，**不是**过采样（oversampled，$D<M$）版本。两者共享同一 polyphase + DFT 框架，但在抽取因子、邻道抑制能力和实现复杂度上有本质区别，下文原理 3 将分别阐述。

## 一、通用数学物理原理

### 原理 1：多相分解（Polyphase Decomposition）

**解决的问题**：一个长为 $L$ 的 FIR 滤波器 $h[n]$ 工作在高采样率 $f_s$ 上时，每秒要做 $L$ 次乘加。若该滤波后还要做 $M$ 倍抽取（保留每 $M$ 个样本中的一个），那么被丢弃的 $M-1$ 个样本的计算完全是浪费。如何重排滤波器结构，使乘加只针对实际保留的样本、并让各分支在 $1/M$ 低速率上运行？

#### 1.1 分解定义

将滤波器冲激响应按 **下标对 $M$ 取模** 分组，得到 $M$ 个子序列（polyphase components）：

$$e_p[n] = h[nM + p], \quad p = 0, 1, \dots, M-1$$

对应的 $z$ 变换（Type-1 多相表示，参考资料 [2][4]）：

$$H(z) = \sum_{n=0}^{L-1} h[n] z^{-n} = \sum_{p=0}^{M-1} z^{-p} E_p(z^M)$$

其中

$$E_p(z) = \sum_{n} h[nM + p]\, z^{-n}$$

是第 $p$ 个多相分支滤波器，长度约为 $L/M$。

**符号说明**：
- $h[n]$：原型 FIR 滤波器冲激响应，长 $L$（通常取 $L = K\cdot M$，$K$ 为整数，称为 taps/branch）；
- $M$：信道数（= 分支数 = 多相分解因子）；
- $e_p[n]$：第 $p$ 个多相分支的冲激响应；
- $E_p(z)$：第 $p$ 个多相分支的传递函数；
- $z^{-p}$：分支延迟，用于把 $M$ 个分支重新交织还原原滤波器。

#### 1.2 Noble 恒等式——抽取前移

多相分解的威力来自 Noble 第一恒等式（参考资料 [2][5]）：滤波 $H(z)$ 后再 $M$ 倍抽取，等价于先 $M$ 倍抽取再滤波 $H(z^M)$：

$$\left(H(z)\, X(z)\right) \downarrow_M \;=\; \left(H(z^M)\, \left(X(z) \downarrow_M\right)\right)$$

把 $H(z) = \sum_p z^{-p} E_p(z^M)$ 代入并前移抽取，得到 **先抽取、再在低速率上做多相滤波** 的结构：

$$y[m] = \sum_{p=0}^{M-1} \left( (x_p * e_p)[m] \right) \cdot (\text{延迟对齐})$$

其中 $x_p[m] = x[mM + p]$ 是输入的第 $p$ 个多相子序列。这样：
- 每个分支滤波器 $e_p$ 长度仅 $L/M$；
- 运行速率仅 $f_s/M$；
- 总乘法量从 $L$ 降到 $L/M$（按输出样本计），节省因子 $M$。

#### 1.3 前提与边界

- $L$ 应为 $M$ 的整数倍，否则需补零或截断；
- 多相分解是 **精确恒等变换**，不引入任何近似——原滤波器与多相形式逐样本等价（参考资料 [4]）；
- 仅对 FIR 直接形式有意义；IIR 的多相分解存在但反馈部分仍需高速率计算。

#### 1.4 直观小例

设 $M=2$，$h[n]=[h_0,h_1,h_2,h_3]$（$L=4$）。则
- $e_0[n]=[h_0,h_2]$（偶数下标）
- $e_1[n]=[h_1,h_3]$（奇数下标）

$H(z)=h_0 + h_1 z^{-1} + h_2 z^{-2} + h_3 z^{-3} = E_0(z^2) + z^{-1} E_1(z^2)$，其中 $E_0(z)=h_0+h_2 z^{-1}$，$E_1(z)=h_1+h_3 z^{-1}$。两支路各长 2，可在半速率上运行。

### 原理 2：均匀 DFT 调制滤波器组（Uniform DFT Filter Bank / 分析滤波器组）

**解决的问题**：要把宽带信号 $x[n]$ 分成 $M$ 个等宽子带，最朴素的做法是用 $M$ 个带通滤波器 $h_k[n]$ 并行滤波（每个调到不同中心频率），复杂度 $O(M^2 L)$。如何让这 $M$ 个带通滤波器共享同一组系数、并用一次 $M$ 点 FFT 同时算出全部信道？

#### 2.1 复调制带通滤波器组

取一个截止频率 $\pi/M$ 的 **原型低通滤波器** $h_0[n]$（实系数），通过复指数调制得到第 $k$ 个信道的带通滤波器（参考资料 [3][6]）：

$$h_k[n] = h_0[n]\, e^{j \frac{2\pi}{M} k n}, \quad k = 0, 1, \dots, M-1$$

$$H_k(z) = H_0\!\left(z\, e^{-j 2\pi k/M}\right)$$

第 $k$ 个信道中心频率为 $\omega_k = 2\pi k/M$（即 $f_k = k f_s/M$），信道间距 $\Delta f = f_s/M$。这 $M$ 个滤波器覆盖 $[0, f_s)$（或 $[-f_s/2, f_s/2)$）的整个频带，构成 **均匀滤波器组**。

#### 2.2 多相 + DFT 的关键化简

对 $h_k[n]$ 做 Type-1 多相分解并代入调制因子（参考资料 [3] 推导）：

$$H_k(z) = \sum_{p=0}^{M-1} e^{-j \frac{2\pi}{M} k p}\, z^{-p}\, E_p\!\left(z^M e^{-j 2\pi k \cdot 0}\right)$$

当抽取因子 $D=M$（临界抽取，见原理 3）时，$E_p(z^M)$ 在抽取后变为 $E_p(z)$，此时第 $k$ 个信道（抽取后）输出为：

$$y_k[m] = \sum_{p=0}^{M-1} g_p[m]\, W_M^{k p}, \qquad W_M = e^{-j 2\pi/M}$$

其中

$$g_p[m] = (x_p * e_p)[m]$$

是第 $p$ 个多相分支滤波后的输出。**这正是 $\{g_p[m]\}_{p=0}^{M-1}$ 的 $M$ 点 DFT**：

$$y_k[m] = \mathrm{DFT}_M\!\left\{ g_0[m], g_1[m], \dots, g_{M-1}[m] \right\}[k]$$

#### 2.3 结构含义

- $M$ 个带通滤波器 **共享同一组多相系数** $e_p$，只是通过 DFT 旋转因子区分信道；
- 用一次 $M$ 点 FFT（复杂度 $O(M\log_2 M)$）替代 $M$ 次独立 DFT（$O(M^2)$）；
- 总复杂度从朴素带通组的 $O(M^2 L)$ 降到 $O(L + M\log_2 M)$（按输出块计）。

#### 2.4 前提与边界

- 原型低通 $h_0$ 必须有良好的阻带衰减，否则邻道泄漏（spectral leakage）严重；
- 临界抽取下，各信道过渡带必然重叠并产生 **混叠（aliasing）**——这是分析端无法避免的，只在综合端（synthesis bank）配合时可抵消；若要求分析端无混叠，需过采样（见原理 3）；
- 信道数 $M$ 与 DFT 点数相同；如需 $N$ 点输出但 $M$ 个物理信道，可补零 FFT。

### 原理 3：多速率抽取与信道化（临界抽取 vs 过采样）

**解决的问题**：信道化把宽带信号分解为 $M$ 个子带后，每个子带带宽仅 $f_s/M$，按 Nyquist 理论采样率可降到 $f_s/M$。如何选抽取因子 $D$？$D=M$ 与 $D<M$ 各有何代价？

#### 3.1 临界抽取（Critically Sampled，$D=M$）

抽取因子等于信道数：$D=M$。每个信道输出速率 $f_{out} = f_s/M = \Delta f$，恰好等于信道间距。

- **优点**：输出总样本率 $M \cdot f_s/M = f_s$，与输入相同，无冗余；计算量最小；FFT 点数 = 信道数 = $M$。
- **代价**：原型滤波器过渡带必须落在信道边界内，否则邻道混叠进入通带。实际 FIR 长度有限，过渡带非零，故 **信道边界附近必然存在混叠盲区**，对落在边界上的信号失真较大。
- 适用：各信号已知位于信道中心附近、或后续综合端能抵消混叠的场景。

#### 3.2 过采样（Oversampled，$D<M$）

抽取因子 $D<M$，输出速率 $f_s/D > \Delta f$（参考资料 [7][8]）。

- **优点**：每个信道带宽大于信号占据的子带，过渡带可落在冗余谱区内，通带内无混叠；邻道抑制更好。
- **代价**：输出总样本率 $M \cdot f_s/D > f_s$，存在冗余；通常需用 $N$ 点 FFT（$N \geq M$，常取 $N=2M$）并把 $M$ 条多相分支扩展为 $N$ 条，结构更复杂。
- 过采样因子 $I = M/D$ 常取 2（"2× 过采样 PFB"，参考资料 [7]）。

#### 3.3 信道排列（even vs odd stacking）

中心频率布局有两种约定：
- **偶型排列（even stacking）**：$f_k = k f_s/M$，$k=0,\dots,M-1$，覆盖 $[0, f_s)$；
- **奇型排列（odd stacking）**：$f_k = (k+1/2) f_s/M$，覆盖 $[-f_s/2M, \dots]$。

两者对应不同的换向器加载方向和 FFT 后是否需要频移，cuSignal 的选择见第二节。

#### 3.4 前提与边界

- 抽取必须在滤波之后（或经 Noble 恒等式前移到 polyphase 分支内），否则直接抽取会引入不可恢复的混叠；
- 临界抽取是 cuSignal 采用的简化形式，**零重叠（zero overlap）**，对边界信号有失真——这是工程简化，非算法本质限制。

完成通用原理检索后，本节只读查看 `Learning/cusignal-23.08.00` 中 `channelize_poly` 的接口与定义，识别其算法选择（不展开逐行语法，那是阶段二的任务）。

### cuSignal 算法 1：临界抽取多相 DFT 分析滤波器组（GPU 主路径）

**输入条件**：
- `x`：1-D 输入信号（`float32/complex64` 或 `float64/complex128`）；
- `h`：1-D 原型滤波器，长度必须能被 `n_chans` 整除；
- `n_chans`：信道数 $M$；每支路 taps $K = \mathrm{len}(h)/M \le 32$（GPU kernel 硬限制）。

**执行步骤**：
1. 将 `h` 多相分解为 $M$ 条支路，每条长 $K$；
2. 换向器每 $M$ 个输入样本产生一个输出块（临界抽取 $D=M$）；
3. 各支路做 polyphase FIR 滤波（含共轭、翻转等信道排列处理）；
4. 对 $M$ 条支路输出做 $M$ 点 FFT（共轭 + 转置用于信道排序）。

**核心公式**：即原理 2 的 $y_k[m] = \mathrm{DFT}_M\{g_p[m]\}[k]$，其中 $g_p[m]$ 由 polyphase kernel 算出。

**输出**：形状 $(M, n_{pts})$ 的复数矩阵，$n_{pts} = \mathrm{len}(x)/M$，第 $k$ 行为第 $k$ 个信道的基带时域样本。

**源码证据**（路径相对于 `ZKX_dev/`，行号按只读基准 `ZKX/cusignal-23.08.00`）：
- 公开导出：`python/cusignal/__init__.py:40`（`channelize_poly`），`python/cusignal/filtering/__init__.py:15`；
- 函数定义：`python/cusignal/filtering/filtering.py:1172-1225`，签名 `def channelize_poly(x, h, n_chans):`；
- docstring 明确算法性质：`filtering.py:1192-1194` 写"Currently only supports simple channelizer where channel spacing is equivalent to the number of channels used (zero overlap). Number of filter taps (len of filter / n_chans) must be <=32."——这印证临界抽取 + 简化实现；
- 多相 FIR 由 CUDA kernel 完成：`filtering.py:28` 导入 `from ._channelizer_cuda import _channelizer`，调用见 `filtering.py:1223`；
- kernel 分发与线程块配置：`python/cusignal/filtering/_channelizer_cuda.py:68-118`，按 `n_taps`（$\le 8/16/32$）选 `channelizer_8x8/16x16/32x32` 三档 kernel，block 为 $(K,K)$、grid 沿信道维与 SM 维展开；

### cuSignal 算法 2：CPU 参考实现（仅用于测试比对）

**位置**：`python/cusignal/test/test_filtering.py:44-94`，函数 `channelize_poly_cpu`。

**执行步骤**（与算法 1 数学等价，纯 NumPy/SciPy 实现）：
1. `h` 重排为 $(M, K)$ 并共轭：`np.conj(np.reshape(h, (n_taps, n_chans)).T)`（`test_filtering.py:74`）；
2. 维护 $M \times K$ 的 polyphase 寄存器 `reg`，每块移位：`reg[:,1:n_taps] = reg[:,0:n_taps-1]`（`:87`）；
3. 换向器加载并共轭翻转：`reg[:,0] = np.conj(np.flipud(x[nn:nn+n_chans]))`（`:88`）；
4. 各支路点积：`vv[mm] = np.dot(reg[mm,:], h[mm,:].T)`（`:90`）；
5. $M$ 点 FFT 并共轭：`yy[:,i] = np.conj(scipy.fft.fft(vv))`（`:92`）。

**用途**：作为 GPU 结果的正确性基准，不是对外 API；测试类 `TestChannelizePoly`（`test_filtering.py:708-717`）以 `n_chan ∈ {64,128,256}` 参数化比对 CPU 与 GPU 输出。

### 数学算法与工程实现的区分

- **数学算法本身**：临界抽取多相 DFT 分析滤波器组 = 原理 1（多相分解）+ 原理 2（均匀 DFT 滤波器组）+ 原理 3 的临界抽取分支。
- **数组处理/工程实现**（非算法本质）：dtype 提升与分发（`filtering.py:1197-1221`）、`n_taps ≤ 32` 的 kernel 分档（`_channelizer_cuda.py:73-116`）、CuPy FFT 调用、共轭/转置用于信道序排列、GPU grid/block 配置、kernel cache 机制。
- **未采用**：过采样（$D<M$）分支——docstring 明确"zero overlap"，故 cuSignal 不实现原理 3 的过采样变体；综合滤波器组（synthesis bank）也不在本算子范围。

## 四、自检问题

1. **通用原理辨析**：为什么多相分解本身只是恒等重排、不能单独完成信道化？它必须和哪一步结合才能分离信道？
2. **Noble 恒等式的作用**：若不做多相分解、直接用 $M$ 个带通滤波器在 $f_s$ 上滤波再抽取，相比 polyphase+FFT 结构，每输出块的复乘次数大约多多少倍？（提示：$O(M^2 L)$ vs $O(L + M\log_2 M)$）

5. **FFT 点数与信道数**：cuSignal 的 `cp.fft.fft(y)` 沿哪个轴、做几点 FFT？为什么 FFT 点数恰好等于信道数 $M$？
