## 〇、独立原理资格核验

在进入通用原理检索前，先确认 `resample` 在脱离 cuSignal 代码后是否对应一个公认的数学对象或信号处理算法。

`resample`（重采样）对应数字信号处理中被普遍认可的 **频域重采样（Frequency-Domain Resampling）**，又称 **FFT-based Resampling**。该方法由 Smith 在 1991 年系统论述（参考资料 [1]），通过离散傅里叶变换在频域直接调整采样率，是 SciPy、MATLAB 等工具箱的标准方法，被广泛应用于音频处理、地震信号分析、医学成像等领域。IEEE Signal Processing Letters 2026 年发表的 "Suppression of Nyquist Ringing in FFT-Based Sample Rate Conversion"（参考资料 [2]）明确将此方法作为采样率转换的基础技术，说明其在学术界和工业界的成熟地位。

因此 `resample` 拥有独立的数学物理原理，可以独立检索，**不是** dispatcher、helper、索引生成器或便捷别名。其核心由四个公认原理支撑：Nyquist-Shannon采样定理与多速率信号处理基础、频域重采样方法、抽取与插值的组合、离散傅里叶变换的性质，下文分别编号阐述。

需要注意：cuSignal `resample` 的 docstring 明确写"The resampling is performed by shortening or zero-padding the FFT of x. This has the advantages of providing an ideal antialiasing filter... The main drawback is the requirement of assuming x to be a periodic signal."，即采用 **周期信号假设** 的简化版本，不适用于非周期信号或边缘敏感的应用场景。这是工程简化，非算法本质限制。

## 一、通用数学物理原理

### 原理 1：Nyquist-Shannon 采样定理与多速率信号处理基础

**解决的问题**：数字信号处理系统中，不同模块可能需要不同的采样率。例如，音频系统中 CD 的 44.1 kHz 与专业音频的 48 kHz，或软件无线电中 ADC 采样率与信号带宽的匹配。如何在保持信号信息的前提下，改变离散时间序列的采样率？

#### 1.1 Nyquist-Shannon 采样定理

连续时间信号 $x_c(t)$ 被采样为离散序列 $x[n] = x_c(nT_s)$ 后，若原信号带宽 $B < f_s/2$（$f_s = 1/T_s$ 为采样率），则可通过理想低通滤波完美重建原信号。频域上，采样信号 DTFT 为（参考资料 [3]）：

$$X(e^{j\omega}) = \frac{1}{T_s} \sum_{k=-\infty}^{\infty} X_c\left(j\frac{\omega - 2\pi k}{T_s}\right)$$

其中 $X_c(j\Omega)$ 为连续时间 Fourier 变换，$\omega = 2\pi f/f_s$ 为归一化频率。

**关键结论**：
- 采样率 $f_s$ 必须 $\geq 2B$ 才能避免混叠；
- 频谱在 $[-\pi, \pi)$ 区间内完整保留原信号信息。

#### 1.2 多速率系统的需求

当系统中存在多个不同采样率时，需要进行 **采样率转换（Sample Rate Conversion, SRC）**：
- **降采样（抽取，decimation）**：降低采样率，减少数据量和计算量；
- **升采样（插值，interpolation）**：提高采样率，满足更高频率分辨率需求；
- **有理分数转换**：$f_{new} = \frac{L}{M} f_{old}$，其中 $L, M$ 为正整数。

**符号说明**：
- $f_s$：原始采样率；
- $T_s = 1/f_s$：采样间隔；
- $N$：原始样本数；
- $N'$：目标样本数；
- $R = N'/N$：采样率变化比例。

### 原理 2：频域重采样方法（Frequency-Domain Resampling）

**解决的问题**：传统时域重采样（如多相滤波器）需要设计复杂的滤波器并处理边界效应。如何利用 DFT 的性质，在频域直接完成采样率转换？

#### 2.1 核心思想

利用 DFT 的 **频谱采样** 性质：$N$ 点 DFT 对应频域 $N$ 个等间隔采样点。改变样本数等价于改变频域采样密度，可通过频谱的 **补零（zero-padding）** 或 **截断（truncation）** 实现（参考资料 [1][2]）。

**算法步骤**：

1. **时域 → 频域**：计算 $N$ 点 FFT，$X[k] = \mathrm{FFT}\{x[n]\}$；
2. **频谱调整**：
   - **升采样（$N' > N$）**：在频谱中央（Nyquist 频率附近）补零；
   - **降采样（$N' < N$）**：截断高频分量；
3. **频域 → 时域**：计算 $N'$ 点 IFFT，$x'[n] = \mathrm{IFFT}\{X'[k]\} \cdot \frac{N'}{N}$。

#### 2.2 数学推导

设原始信号 $x[n]$ 的 DTFT 为 $X(e^{j\omega})$，$N$ 点 DFT 为：

$$X[k] = X(e^{j2\pi k/N}), \quad k = 0, 1, \dots, N-1$$

当进行升采样（补零）时，新频谱 $X'[k]$ 为：

$$X'[k] = \begin{cases}
X[k], & k = 0, 1, \dots, \lfloor N/2 \rfloor \\
0, & k = \lfloor N/2 \rfloor + 1, \dots, N' - \lceil N/2 \rceil - 1 \\
X[k - N' + N], & k = N' - \lceil N/2 \rceil, \dots, N'-1
\end{cases}$$

时域插值信号为：

$$x'[n] = \frac{N'}{N} \cdot \mathrm{IFFT}\{X'[k]\}$$

**关键性质**：
- 补零等效于频域插值，对应时域的理想 sinc 插值（假设周期延拓）；
- 截断等效于理想低通滤波，截止频率为新的 Nyquist 频率。

#### 2.3 前提与边界

- **周期性假设**：信号必须被视为周期的，否则会在边界产生 Gibbs 现象（振铃）；
- **频谱对称性**：实数信号的 DFT 满足 Hermitian 对称性，补零/截断必须保持此性质；
- **Nyquist 频率处理**：当 $N$ 为偶数时，Nyquist 频率分量 $X[N/2]$ 需特殊处理（分半或求和）；
- **理想滤波器**：截断提供理想砖墙式（brick-wall）低通滤波，无过渡带，但会引起时域振铃。

---

### 原理 3：抽取与插值的组合

**解决的问题**：在实际系统中，采样率转换往往需要同时处理升采样和降采样。如何将两者统一为一个框架？

#### 3.1 抽取（Decimation）

降采样 $M$ 倍的定义（参考资料 [4]）：

$$y[m] = x[Mm]$$

频域效应：

$$Y(e^{j\omega}) = \frac{1}{M} \sum_{k=0}^{M-1} X\left(e^{j(\omega - 2\pi k)/M}\right)$$

**混叠风险**：若原信号带宽 $> \pi/M$，降采样后会产生混叠，必须先用截止频率 $\pi/M$ 的低通滤波器进行抗混叠滤波。

#### 3.2 插值（Interpolation）

升采样 $L$ 倍的定义（参考资料 [4]）：

$$x_e[n] = \begin{cases}
x[n/L], & n = 0, \pm L, \pm 2L, \dots \\
0, & \text{otherwise}
\end{cases}$$

频域效应：

$$X_e(e^{j\omega}) = X(e^{j\omega L})$$

**镜像效应**：插值会在 $[0, 2\pi)$ 区间产生 $L-1$ 个镜像副本，必须用截止频率 $\pi/L$ 的低通滤波器去除。

#### 3.3 有理分数转换 $L/M$

将插值 $L$ 倍和抽取 $M$ 倍组合（参考资料 [5]）：

$$x \xrightarrow{\text{插值 } L} x_e \xrightarrow{\text{滤波}} x_f \xrightarrow{\text{抽取 } M} y$$

最终采样率：$f_{new} = \frac{L}{M} f_{old}$

滤波器截止频率必须为：

$$\omega_c = \min\left(\frac{\pi}{L}, \frac{\pi}{M}\right)$$

**与频域重采样的关系**：
- 当 $L/M = N'/N$ 时，有理分数转换等价于频域重采样；
- 频域方法避免了设计时域滤波器，直接在频域完成截断/补零。

### 原理 4：离散傅里叶变换的性质

**解决的问题**：理解频域重采样的精度、误差和适用边界，需要掌握 DFT 的核心性质。

#### 4.1 DFT 定义与周期延拓

$N$ 点 DFT 定义为：

$$X[k] = \sum_{n=0}^{N-1} x[n] e^{-j2\pi kn/N}, \quad k = 0, 1, \dots, N-1$$

IDFT 为：

$$x[n] = \frac{1}{N} \sum_{k=0}^{N-1} X[k] e^{j2\pi kn/N}, \quad n = 0, 1, \dots, N-1$$

**周期性**：DFT 隐式假设 $x[n]$ 和 $X[k]$ 都是周期的，周期为 $N$：

$$x[n] = x[n + pN], \quad X[k] = X[k + pN], \quad p \in \mathbb{Z}$$

#### 4.2 补零性质

在 $x[n]$ 末端补零得到 $\tilde{x}[n]$（长度 $N' > N$）：

$$\tilde{x}[n] = \begin{cases}
x[n], & n = 0, 1, \dots, N-1 \\
0, & n = N, N+1, \dots, N'-1
\end{cases}$$

对应 DFT $\tilde{X}[k]$ 为原 DFT $X[k]$ 的 **插值**：

$$\tilde{X}[k] = X\left(e^{j2\pi k/N'}\right)$$

即 $\tilde{X}[k]$ 是 $X(e^{j\omega})$ 在 $[0, 2\pi)$ 上更密集的采样。

#### 4.3 频域补零与时域插值

在 $X[k]$ 的中央（Nyquist 频率附近）补零，等价于时域插值。例如，将 $N$ 点 DFT 补零为 $2N$ 点：

$$X'[k] = \begin{cases}
X[k], & k = 0, \dots, \lfloor N/2 \rfloor \\
0, & k = \lfloor N/2 \rfloor + 1, \dots, 2N - \lceil N/2 \rceil - 1 \\
X[k - 2N + N], & k = 2N - \lceil N/2 \rceil, \dots, 2N-1
\end{cases}$$

时域信号 $x'[n]$ 为 $x[n]$ 的理想 sinc 插值（假设周期延拓）。

#### 4.4 前提与边界

- **频谱泄漏**：非整周期信号在边界产生泄漏，可通过窗函数缓解；
- **栅栏效应**：DFT 只给出频域离散采样，补零可提高频率分辨率，但不增加信息；
- **振铃现象**：频域截断等效理想低通，在时域边界产生 Gibbs 振铃（参考资料 [2]）。

## 二、cuSignal 23.08.00 实际采用的算法

完成通用原理检索后，本节只读查看 `Learning/cusignal-23.08.00` 中 `resample` 的接口与定义，识别其算法选择（不展开逐行语法，那是阶段二的任务）。

### cuSignal 算法 1：FFT 频域重采样（主路径）

**输入条件**：
- `x`：输入信号（`float32/complex64` 或 `float64/complex128`）；
- `num`：目标样本数（可大于或小于原始样本数）；
- `axis`：重采样轴（默认 0）；
- `window`：频域窗函数（可选，用于抑制振铃）；
- `domain`：输入域（`'time'` 或 `'freq'`）。

**执行步骤**：
1. 判断输入域，若为时域则执行 FFT：`X = fft(x, axis=axis)`；
2. 若指定 `window`，在频域应用窗函数：`X = X * W`；
3. 根据目标样本数 `num` 与原始样本数 `Nx` 的关系：
   - 若 `num < Nx`（降采样）：截断高频分量，保留 $[0, \text{Nyquist}]$ 和 $[-\text{Nyquist}, 0]$ 区间；
   - 若 `num > Nx`（升采样）：在 Nyquist 频率附近补零；
4. 处理 Nyquist 频率分量（当 $N$ 为偶数时）：根据升/降采样分别进行分半或求和；
5. 执行 IFFT 并缩放：`y = ifft(Y, axis=axis) * (num / Nx)`；
6. 若输入为实数，取实部：`y = y.real`。

**核心公式**：

$$y[n] = \mathrm{IFFT}\{\tilde{X}[k]\} \cdot \frac{N'}{N}$$

其中 $\tilde{X}[k]$ 为补零/截断后的频谱。

**输出**：重采样后的信号 $y[n]$（长度 `num`），以及可选的新时间轴 `new_t`。

**源码证据**（路径相对于 `ZKX_dev/`，行号按只读基准 `ZKX/cusignal-23.08.00`）：
- 公开导出：`python/cusignal/__init__.py:40`（`resample`），`python/cusignal/filtering/__init__.py:15`；
- 函数定义：`python/cusignal/filtering/resample.py:148-299`，签名 `def resample(x, num, t=None, axis=0, window=None, domain="time")`；
- FFT 调用：`resample.py:242` `cp.fft.fft(x, axis=axis)`；
- 窗函数处理：`resample.py:248-260`，支持 callable、array 或窗函数名；
- 频谱调整：`resample.py:262-288`，补零/截断逻辑，包括 Nyquist 频率分量的特殊处理；
- IFFT 调用：`resample.py:290` `cp.fft.ifft(Y, axis=axis) * (float(num) / float(Nx))`；
- 实数处理：`resample.py:292-293`。

### 数学算法与工程实现的区分

- **数学算法本身**：频域重采样 = 原理 2（FFT-based Resampling）+ 原理 4（DFT 性质），核心步骤为 FFT → 频谱补零/截断 → IFFT；
- **数组处理/工程实现**（非算法本质）：
  - CuPy FFT 调用与 dtype 分发；
  - 窗函数生成与应用（用于抑制 Gibbs 振铃）；
  - Nyquist 频率分量的特殊处理（保持 Hermitian 对称性）；
  - 多维数组的轴选择（`axis` 参数）；
  - 时间轴计算（`t` 参数）。
- **未采用**：时域多相滤波器方法（由 `resample_poly` 提供），以及抗混叠滤波器的显式设计（由频域截断隐式完成）。

1. **周期性假设的含义**：为什么 `resample` 的 docstring 强调"signal is assumed to be periodic"？若输入信号在边界不满足周期性，会产生什么现象？如何缓解？
2. **频域补零的数学意义**：在频谱中央补零，为什么等价于时域插值？这与原理 4 的哪个性质相关？
3. **Nyquist 频率分量的处理**：当 $N$ 为偶数时，为什么要对 $X[N/2]$ 分半（升采样）或求和（降采样）？若不处理会导致什么问题？
4. **理想低通滤波的实现**：频域截断为什么能提供"ideal antialiasing filter"？与时域滤波器相比，有什么优势和劣势？
5. **窗函数的作用**：为什么 `window` 参数能"alleviate ringing in the resampled values"？这与哪个原理的哪个边界问题相关？
6. **与 `resample_poly` 的区别**：cuSignal 中 `resample` 与 `resample_poly` 各自采用哪个原理？各自的适用场景是什么？
7. **源码证据**：`resample` 的公开导入路径、函数定义文件与行号、FFT 与 IFFT 调用位置分别是什么？频谱补零/截断的核心逻辑在哪一行？
8. **边界与限制**：若输入信号长度 $N$ 或目标长度 `num` 为大质数，会有什么性能问题？如何选择合适的重采样方法？
