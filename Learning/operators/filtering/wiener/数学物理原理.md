# wiener 算子学习 — 数学物理原理

> 本文件对应 `Learning/operators/filtering/wiener/` 目录，记录阶段一（数学与物理原理）。
> 算子编号：官方 53 项中的第 46 项，模块 `filtering`，名称 `wiener`（见 `Learning/cusignal.md`）。
> 算子一句话描述：Wiener 滤波 $\hat{y}=\mu+\frac{\sigma^2-\nu^2}{\sigma^2}(x-\mu)$，最小均方误差降噪。

---

## 〇、独立原理资格核验

在进入通用原理检索前，先确认 `wiener` 在脱离 cuSignal 代码后是否对应一个公认的数学对象或信号处理算法。

`wiener`（Wiener 滤波 / 维纳滤波）是信号处理与图像处理中被普遍认可的统计最优估计方法。由 Norbert Wiener 在 1940 年代提出（1949 年专著 *Extrapolation, Interpolation, and Smoothing of Stationary Time Series*），其核心是在已知信号与噪声二阶统计量的条件下，设计使均方误差（MSE）最小的线性滤波器。IEEE 将其列为信号处理的基础概念之一（IEEE TechNav: Wiener filter）。在图像处理领域，Jae S. Lim 在其经典教材 *Two-Dimensional Signal and Image Processing*（Prentice Hall, 1990, p. 536–548）中给出了空间域逐像素自适应 Wiener 滤波的推导，即 SciPy `signal.wiener` 和 MATLAB `wiener2` 所采用的算法。因此 `wiener` 拥有独立的数学物理原理，可以独立检索。

需要注意：cuSignal/SciPy 的 `wiener` 并非频率域全局 Wiener 滤波器（原理 1），而是其空间域逐像素自适应变体（原理 2，即 Lee 滤波）。两者虽共享同一 MMSE 框架，但在假设、实现和适用场景上有本质区别，下文将分别阐述。

## 一、通用数学物理原理

### 原理 1：频率域全局 Wiener 滤波（经典 Wiener 滤波）

**解决的问题**：观测信号 $y(t)$ 是原始信号 $s(t)$ 与加性噪声 $n(t)$ 的叠加（或经过退化系统 $h$ 后再加噪），如何在频率域设计一个线性滤波器 $G(f)$，使估计 $\hat{s}(t)$ 与真实 $s(t)$ 的均方误差最小？

#### 1.1 信号模型

连续时间下：

$$y(t) = h(t) * s(t) + n(t)$$

频率域：

$$Y(f) = H(f)S(f) + N(f)$$

其中 $h(t)$ 为退化系统脉冲响应，$n(t)$ 为加性噪声，$s(t)$ 与 $n(t)$ 不相关。

#### 1.2 MMSE 准则与 Wiener-Hopf 方程

最小化均方误差：

$$J = E\left[|s(t) - \hat{s}(t)|^2\right] = E\left[|s(t) - g(t) * y(t)|^2\right]$$

对 $g(\tau)$ 求变分（正交原理：估计误差 $s-\hat{s}$ 必须与观测 $y$ 正交），得到 Wiener-Hopf 方程：

$$R_{sy}(\tau) = \int_{-\infty}^{\infty} g(\alpha) R_{yy}(\tau - \alpha)\,d\alpha$$

其中 $R_{sy}$ 为信号与观测的互相关，$R_{yy}$ 为观测的自相关。

在频率域，非因果 Wiener 滤波器有闭式解：

$$G(f) = \frac{S_{sy}(f)}{S_{yy}(f)}$$

当噪声与信号不相关且 $H=1$（纯加噪）时，$S_{sy} = S_{ss}$，$S_{yy} = S_{ss} + S_{nn}$，故：

$$G(f) = \frac{S_{ss}(f)}{S_{ss}(f) + S_{nn}(f)} = \frac{\text{SNR}(f)}{1 + \text{SNR}(f)}$$

**符号说明**：
- $S_{ss}(f)$：信号的功率谱密度；
- $S_{nn}(f)$：噪声的功率谱密度；
- $\text{SNR}(f) = S_{ss}(f)/S_{nn}(f)$：频率 $f$ 处的信噪比；
- $G(f) \in [0, 1]$：频率域增益，SNR 高处接近 1（保留信号），SNR 低处接近 0（抑制噪声）。

#### 1.3 离散形式

对离散信号 $y[n] = s[n] + n[n]$，FIR Wiener 滤波器的系数 $\mathbf{w}$ 满足正规方程（离散 Wiener-Hopf）：

$$\mathbf{R}_{yy}\mathbf{w} = \mathbf{r}_{sy}$$

其中 $\mathbf{R}_{yy} = E[\mathbf{y}\mathbf{y}^H]$（自相关矩阵），$\mathbf{r}_{sy} = E[s[n]\mathbf{y}^*]$（互相关向量）。

#### 1.4 前提与边界

- 信号与噪声为**广义平稳（WSS）**随机过程；
- 信号与噪声**不相关**；
- 滤波器为**线性时不变（LTI）**；
- 需要知道信号与噪声的**功率谱密度**或自相关函数（全局统计量）。

**局限性**：全局 Wiener 滤波假设整幅图像/整段信号共享相同的统计特性。但真实图像中纹理、边缘、平坦区共存，全局模型无法兼顾，导致边缘过模糊、平坦区去噪不足。这正是局部自适应 Wiener 滤波（原理 2）的出发点。

### 原理 2：空间域局部自适应 Wiener 滤波（Lee 滤波）

**解决的问题**：克服全局 Wiener 滤波对非平稳信号的局限，在每个像素的邻域内独立估计局部统计量，实现空间可变的自适应去噪。

#### 2.1 信号模型与假设

设观测到的像素值为 $x$，真实信号为 $s$，噪声为 $n$，加性模型：

$$x = s + n$$

假设：
1. 噪声 $n$ 是零均值、方差为 $\nu^2$ 的白噪声，与信号 $s$ 不相关；
2. 信号 $s$ 在局部邻域内近似平稳，均值为 $\mu$、方差为 $\sigma_s^2$；
3. 邻域内信号与噪声不相关：$E[(s-\mu)n] = 0$。

由假设可得观测的局部统计量与信号统计量之间的关系：

- 局部均值：$\mu_x = E[x] = \mu + 0 = \mu$
- 局部方差：$\sigma_x^2 = \text{Var}(x) = \text{Var}(s) + \text{Var}(n) = \sigma_s^2 + \nu^2$

因此信号方差可从局部观测方差中减去噪声方差估计：

$$\hat{\sigma}_s^2 = \sigma_x^2 - \nu^2$$

#### 2.2 MMSE 估计推导

在给定局部均值 $\mu$ 和局部方差 $\sigma_x^2$ 的条件下，对信号 $s$ 做**线性 MMSE 估计**。假设估计形式为：

$$\hat{s} = a \cdot x + b$$

其中 $a$ 和 $b$ 为待定系数。最小化 $E[(s - \hat{s})^2]$：

$$E[(s - ax - b)^2]$$

展开并对 $a$、$b$ 求偏导令为零。利用 $E[s] = \mu$、$E[x] = \mu$、$\text{Cov}(s, x) = \text{Var}(s) = \sigma_s^2$、$\text{Var}(x) = \sigma_x^2$：

对 $b$：

$$\frac{\partial}{\partial b} E[(s-ax-b)^2] = -2E[s-ax-b] = 0 \implies b = \mu - a\mu = \mu(1-a)$$

对 $a$：

$$\frac{\partial}{\partial a} E[(s-ax-b)^2] = -2E[(s-ax-b)(x)] = 0$$

代入 $b = \mu(1-a)$：

$$E[(s - ax - \mu + a\mu) \cdot x] = E[(s-\mu)x] - aE[(x-\mu)x] = 0$$

$$\text{Cov}(s, x) - a\cdot\text{Var}(x) = 0 \implies a = \frac{\text{Cov}(s, x)}{\text{Var}(x)} = \frac{\sigma_s^2}{\sigma_x^2}$$

代入 $\sigma_s^2 = \sigma_x^2 - \nu^2$：

$$a = \frac{\sigma_x^2 - \nu^2}{\sigma_x^2} = 1 - \frac{\nu^2}{\sigma_x^2}$$

最终估计：

$$\boxed{\hat{s} = \mu + \left(1 - \frac{\nu^2}{\sigma_x^2}\right)(x - \mu)}$$

这就是 SciPy `signal.wiener` 和 cuSignal `wiener` 所实现的核心公式。

#### 2.3 物理含义

- 当 $\sigma_x^2 \gg \nu^2$（高信号方差区，如边缘/纹理）：$a \approx 1$，$\hat{s} \approx x$，几乎不过滤，保留细节；
- 当 $\sigma_x^2 \approx \nu^2$（低信号方差区，如平坦区）：$a \approx 0$，$\hat{s} \approx \mu$，输出退化为局部均值，强力平滑；
- 当 $\sigma_x^2 < \nu^2$（局部方差低于噪声方差）：$a < 0$ 会导致估计方差为负，不合理。此时直接令 $\hat{s} = \mu$（即 $a = 0$）。

最后一条的截断处理 $\sigma_x^2 < \nu^2 \Rightarrow \hat{s} = \mu$ 是实际实现中的工程决策，防止出现负的权重或放大的噪声。

#### 2.4 符号说明

| 符号 | 含义 | 维度/取值 |
| --- | --- | --- |
| $x$ | 观测像素值 | 标量 |
| $s$ | 真实信号值 | 标量 |
| $n$ | 噪声 | 标量，零均值 |
| $\mu$ | 局部均值 $E[x]$ | 标量 |
| $\sigma_x^2$ | 局部观测方差 $\text{Var}(x)$ | 非负标量 |
| $\sigma_s^2$ | 信号方差 $= \sigma_x^2 - \nu^2$ | 非负标量（截断后） |
| $\nu^2$ | 噪声方差（noise power） | 正标量 |
| $a = 1 - \nu^2/\sigma_x^2$ | 自适应权重 | $[0, 1]$（截断后） |

#### 2.5 连续与离散形式的关系

连续域下，局部统计量由空间邻域的积分近似；离散域下由窗口内像素的求和/均值替代。窗口大小决定了局部平稳假设的近似程度：窗口越大，估计方差越小（更稳定）但空间分辨率越低；窗口越小，空间分辨率越高但方差估计噪声越大。

#### 2.6 前提与边界

- 噪声为**加性、零均值、与信号不相关**的白噪声；
- 局部邻域内信号近似**平稳**（均值和方差缓变）；
- 噪声方差 $\nu^2$ 已知或可估计；
- 窗口大小须为奇数（保证中心对称），且远小于图像尺寸；
- 边界处理采用零填充（cuSignal/SciPy 的选择），边界像素可能失真。

#### 2.7 参数影响

| 参数 | 影响 |
| --- | --- |
| 窗口大小 `mysize` | 增大 → 平滑增强、边缘模糊；减小 → 细节保留但去噪不足 |
| 噪声方差 `noise` | 增大 → 滤波更强（更多像素退化为局部均值）；减小 → 保留更多原始信号 |
| `noise=None`（自动估计） | 取所有局部方差的均值作为噪声方差估计；适用于均匀噪声，但在信号占主导时可能过估计 |

### 原理 3：局部均值与方差的均匀加权估计

**解决的问题**：如何在每个像素的邻域内高效计算局部均值 $\mu$ 和局部方差 $\sigma_x^2$？

#### 3.1 均匀加权（盒式窗口）

设窗口为 $D$ 维，每维大小 $w_1 \times w_2 \times \cdots \times w_D$，窗口总元素数 $W = \prod_{d=1}^{D} w_d$。对以像素 $\mathbf{i}$ 为中心的邻域 $\mathcal{N}(\mathbf{i})$：

**局部均值**：

$$\mu(\mathbf{i}) = \frac{1}{W}\sum_{\mathbf{j} \in \mathcal{N}(\mathbf{i})} x[\mathbf{j}]$$

**局部方差**：

$$\sigma_x^2(\mathbf{i}) = \frac{1}{W}\sum_{\mathbf{j} \in \mathcal{N}(\mathbf{i})} \bigl(x[\mathbf{j}] - \mu(\mathbf{i})\bigr)^2 = \frac{1}{W}\sum_{\mathbf{j} \in \mathcal{N}(\mathbf{i})} x[\mathbf{j}]^2 - \mu(\mathbf{i})^2$$

第二个等式是方差计算的**计算公式**（$E[X^2] - (E[X])^2$），避免两次遍历：先算 $E[X^2]$ 和 $E[X]$，再相减。

#### 3.2 相关/卷积加速

局部均值的求和本质上是输入与全 1 核的**相关（correlate）**运算：

$$\sum_{\mathbf{j} \in \mathcal{N}(\mathbf{i})} x[\mathbf{j}] = (x \star \mathbf{1}_{w_1 \times \cdots \times w_D})[\mathbf{i}]$$

同理，$x^2$ 的局部和是对 $x^2$ 做同样相关。因此计算步骤为：

1. 计算 $S_1 = \text{correlate}(x, \mathbf{1})$（各窗口内像素值之和）；
2. 计算 $S_2 = \text{correlate}(x^2, \mathbf{1})$（各窗口内像素值平方之和）；
3. $\mu = S_1 / W$；
4. $\sigma_x^2 = S_2 / W - \mu^2$。

这就是 cuSignal `wiener` 的核心计算逻辑。相关运算在 GPU 上可用 FFT 加速（cuSignal 使用 `correlate` 函数，内部走 FFT 卷积路径）。

#### 3.3 与其他加权方案的比较

- **均匀加权（盒式）**：cuSignal/SciPy/MATLAB `wiener2` 的选择。计算简单，可用相关/卷积加速；缺点是窗口边缘处权重突变，引入方块效应。
- **高斯加权**：远离中心的像素权重指数衰减，更平滑但计算量更大。
- **自适应加权（如双边滤波）**：同时考虑空间距离和灰度相似性，边缘保持更好，但计算复杂度显著增加。

#### 3.4 与原理 2 的关系

原理 3 是原理 2 的**计算基础**：局部自适应 Wiener 滤波（原理 2）所需的 $\mu$ 和 $\sigma_x^2$ 由原理 3 的均匀加权估计提供。原理 2 是"要算什么"，原理 3 是"怎么算"。

### 原理 4：噪声方差的自动估计

**解决的问题**：当噪声方差 $\nu^2$ 未知时，如何从观测数据中自动估计？

#### 4.1 全局均值法

cuSignal/SciPy 采用的方法：对所有像素的局部方差求全局均值，作为噪声方差的估计：

$$\hat{\nu}^2 = \frac{1}{N}\sum_{\mathbf{i}} \sigma_x^2(\mathbf{i})$$

其中 $N$ 为总像素数，$\sigma_x^2(\mathbf{i})$ 为像素 $\mathbf{i}$ 处的局部方差。

**直觉**：在图像的大部分区域（平坦区和缓变区），局部方差主要来自噪声；只有在边缘和纹理处，局部方差才显著高于噪声方差。取全局均值可以让大量低方差区域"拉低"均值，使其接近噪声方差。

**前提**：图像中平坦/缓变区域占多数；噪声为空间均匀的加性白噪声。

**局限**：如果图像纹理/细节丰富，局部方差全局均值会**过估计**噪声方差，导致滤波不足（$a$ 偏大，保留更多噪声）；如果图像几乎全为平坦区，则估计较为准确。

#### 4.2 其他估计方法

- **均匀区域法**：手动选取图像中已知平坦的区域，直接计算该区域方差；
- **高频能量法**：对图像做高通滤波，取高频分量的方差作为噪声估计；
- **鲁棒估计法**：取局部方差的中位数而非均值，抵抗纹理区域的干扰；
- **最小局部方差法**：取所有局部方差中的最小值作为噪声估计。

cuSignal/SciPy 未采用这些方法，而是选择了最简单的全局均值法。当用户指定 `noise` 参数时则跳过自动估计。

### 原理 5：Wiener 滤波与去卷积/频率域 Wiener 滤波的关系

**解决的问题**：cuSignal/SciPy 的 `wiener` 与教科书中的频率域 Wiener 去卷积滤波器是什么关系？

两者共享同一 MMSE 框架，但有本质区别：

| 对比项 | 频率域全局 Wiener（原理 1） | 空间域局部自适应 Wiener（原理 2） |
| --- | --- | --- |
| 假设 | 全局 WSS | 局部近似平稳 |
| 统计量 | 全局功率谱 $S_{ss}(f), S_{nn}(f)$ | 局部均值 $\mu$、方差 $\sigma_x^2$ |
| 滤波方式 | 频率域乘 $G(f)$ | 空间域逐像素 $a(x-\mu)+\mu$ |
| 退化模型 | $Y=HS+N$（含模糊 $H$） | $x=s+n$（无模糊） |
| 自适应性 | 全局同一滤波器 | 逐像素自适应权重 |
| 边界处理 | DFT 隐含周期边界 | 零填充或镜像 |

SciPy 文档明确指出："This is not the Wiener filter commonly described in image-reconstruction problems but, instead, it is a simple, local-mean filter." cuSignal 的 `wiener` 是 SciPy 的 GPU 加速等价实现，两者算法完全一致。

### cuSignal 算法 1：局部自适应 Wiener 滤波（Lee 滤波）

- **输入条件**：任意 `im`（N 维 CuPy 数组），`mysize` 指定窗口大小，`noise` 指定或自动估计噪声方差。
- **执行步骤**：
  1. 转为 CuPy 数组（`filtering.py:88`）；
  2. 默认窗口 `[3]*ndim`（`filtering.py:89-90`），标量扩展为每维相同（`filtering.py:91-94`）；
  3. 计算窗口元素总数 `lprod`（`filtering.py:96`）；
  4. 用 `correlate(im, ones, "same")` 计算局部像素值之和 `lMean`（`filtering.py:97`）；
  5. 用 `correlate(im**2, ones, "same")` 计算局部像素值平方之和 `lVar`（`filtering.py:98`）；
  6. 调用 GPU kernel `_wiener_prep_kernel` 将求和转为均值和方差：`lMean = sum/W`，`lVar = sumSq/W - mean^2`（`filtering.py:100`，kernel 定义 `filtering.py:31-42`）；
  7. 若 `noise=None`，自动估计噪声方差为所有局部方差的均值（`filtering.py:103-104`）；
  8. 调用 GPU kernel `_wiener_post_kernel` 逐像素执行 Wiener 滤波公式：若 $\sigma_x^2 < \nu^2$ 则输出 $\mu$，否则输出 $\mu + (1-\nu^2/\sigma_x^2)(x-\mu)$（`filtering.py:106`，kernel 定义 `filtering.py:44-60`）。
- **核心公式**：

$$\hat{s}(\mathbf{i}) = \begin{cases} \mu(\mathbf{i}) + \left(1 - \dfrac{\nu^2}{\sigma_x^2(\mathbf{i})}\right)\bigl(x(\mathbf{i}) - \mu(\mathbf{i})\bigr), & \sigma_x^2(\mathbf{i}) \ge \nu^2 \\ \mu(\mathbf{i}), & \sigma_x^2(\mathbf{i}) < \nu^2 \end{cases}$$

- **性质**：核心是原理 2 的逐像素自适应 Wiener 滤波；`correlate` 是计算局部统计的工具（原理 3）；噪声自动估计是原理 4。`_wiener_prep_kernel` 和 `_wiener_post_kernel` 是 GPU 并行化工程实现，算法本身与 SciPy `signal.wiener` 完全等价。
- **源码证据**：`filtering.py:63-106`；辅助 kernel `filtering.py:31-60`；`correlate` 导入自 `..convolution.correlate`（`filtering.py:18`）。

### cuSignal 未采用的方法

cuSignal 的 `wiener` **未**采用：
- 频率域全局 Wiener 滤波（原理 1）：不使用 FFT 域的 $G(f)$ 乘法，而是在空间域逐像素计算；
- 高斯/双边等非均匀加权窗口（原理 3 中提到）：只用均匀加权（全 1 核）；
- 鲁棒噪声估计（原理 4 中提到）：只用全局均值法；
- 去卷积 Wiener 滤波（涉及退化函数 $H$）：不支持模糊核/PSF 输入，只处理纯加性噪声。

原因：cuSignal 的 `wiener` 直接对齐 SciPy `signal.wiener`，后者又对齐 MATLAB `wiener2`，三者的算法完全一致——即 Lee (1980) 提出的空间域局部自适应 Wiener 滤波。该方法是图像去噪中最简单、最广泛使用的自适应滤波器之一。

## 四、可手算的小例子

取 1 维信号 $N=5$，$\mathbf{x}=[10,\,12,\,14,\,11,\,9]$，窗口大小 $w=3$（均匀加权），设噪声方差 $\nu^2=1$。

**步骤 1：计算局部均值**

以 $\mu(2)$ 为例（索引从 0 起算）：

$$\mu(2) = \frac{1}{3}(12+14+11) = \frac{37}{3} \approx 12.33$$

**步骤 2：计算局部方差**

$$\sigma_x^2(2) = \frac{1}{3}(12^2+14^2+11^2) - \mu(2)^2 = \frac{144+196+121}{3} - 12.33^2 = \frac{461}{3} - 152.11 = 153.67 - 152.11 = 1.56$$

**步骤 3：Wiener 滤波**

$\sigma_x^2(2) = 1.56 > \nu^2 = 1$，故：

$$a = 1 - \frac{1}{1.56} = 1 - 0.641 = 0.359$$

$$\hat{s}(2) = 12.33 + 0.359 \times (14 - 12.33) = 12.33 + 0.60 = 12.93$$

对比原始值 $x(2)=14$：Wiener 滤波将偏离局部均值的值向均值方向"拉回"约 64%，体现了自适应降噪。

**验证截断条件**：假设某像素处 $\sigma_x^2 = 0.5 < \nu^2 = 1$，则直接输出 $\mu$。例如 $x=[10,10,10]$ 的三个像素，$\mu=10$，$\sigma_x^2=0$，输出全部为 $10$（局部方差为零，无需滤波，也无需放大噪声）。

## 五、容易混淆的概念与常见误区

1. **"Wiener 滤波"一词的多义性**：信号处理教材中的"Wiener 滤波"通常指频率域全局最优滤波器（原理 1），而 SciPy/cuSignal/MATLAB `wiener2` 的"Wiener"指的是空间域局部自适应版本（原理 2，Lee 滤波）。两者共享 MMSE 思想但实现和假设完全不同，不可混淆。
2. **局部方差 $\sigma_x^2$ 不等于信号方差 $\sigma_s^2$**：$\sigma_x^2 = \sigma_s^2 + \nu^2$（加性模型），信号方差需要减去噪声方差。但实际实现中并不显式计算 $\sigma_s^2$，而是直接用 $\sigma_x^2$ 和 $\nu^2$ 组合出权重 $a = 1 - \nu^2/\sigma_x^2$。
3. **截断条件 $\sigma_x^2 < \nu^2$ 不是数学推导的必然结果**：理论最优线性估计在 $\sigma_x^2 < \nu^2$ 时会给出负权重，这在物理上不合理。截断为 $\hat{s}=\mu$ 是工程决策，保证输出在 $[x, \mu]$ 之间。
4. **`noise=None` 的自动估计可能不准**：当图像细节丰富时，局部方差的全局均值会高于真实噪声方差，导致滤波不足。若已知噪声方差，应显式传入。
5. **窗口大小对结果影响显著**：小窗口（如 3×3）保留细节但去噪弱；大窗口（如 7×7 或更大）去噪强但模糊边缘。没有"最优"窗口大小，需根据噪声水平和信号特性权衡。
6. **零填充边界效应**：`correlate(..., "same")` 在边界处用零填充，使得边界像素的局部均值和方差偏低，可能导致滤波结果在边界处失真。
7. **该滤波器不是去模糊/去卷积**：cuSignal/SciPy 的 `wiener` 只处理加性噪声，不涉及模糊核/PSF。如需去卷积，应使用频率域 Wiener 去卷积（原理 1 的扩展形式），这不是本算子的功能。
