## 4. 数据流与实现层次

外部配置 → Python/C++入口 → runner构造共享状态 → step1…step6顺序更新状态 → Host结果/JSON → 精度、耗时、稳定性证据 → 可视化派生结果。CPU reference用于独立数学基准；GPU wrapper负责显存和调度；CUDA kernel负责并行计算；正式 cuSignal 算子内部实现归 [operators](../operators/) 学习文档。
